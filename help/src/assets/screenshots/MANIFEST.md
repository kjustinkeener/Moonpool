# Screenshot manifest

Images in this folder. Embed from a page two levels under docs root. Convention: `-narrow` in the file name caps display at 340px, `-wide` allows full width, others cap at 680px (see `help/src/styles/screenshots.css`). Annotations are accent-colored outlines and numbered badges. Not captured: Moonpool-owned dashboard windows (static apps open in the browser) and the Notes App running state.
