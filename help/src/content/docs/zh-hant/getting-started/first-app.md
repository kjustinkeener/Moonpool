## 1. 啟動 Moonpool

在 Windows 上，執行 `moonpool.exe` 並按一下 **安裝 Moonpool**（請參閱[安裝](/zh-hant/getting-started/install/)）。在 Linux 上，啟動 AppImage 或已安裝的套件。

Moonpool 第一次執行時，會在側邊欄放入一些範例應用程式（Windows 上有記事本、一個 shell、一個小型網頁伺服器，以及隨附的儀表板）。它們可以直接執行（網頁伺服器需要 Python），你可以先試用，再編輯或刪除。它也會在系統匣中放一個圖示。在 Windows 上，如果沒看到該圖示，請按一下工作列右側的 **^** 箭頭。

## 2. 新增你的應用程式

1. 開啟側邊欄頂端的 **...** 選單，選擇 **新增應用程式**。
2. 輸入 **name**。群組一開始是 `Web apps`，可以保留，也可以改成別的。
3. 若是開發伺服器，就讓 **type** 維持 `web`。
4. 把 **cwd** 設為你的專案資料夾，把 **command** 設為你用來啟動它的命令，例如 `npm run dev`。
5. 把 **port** 設為它監聽的連接埠，把 **url** 設為要開啟的頁面。
6. 儲存。

每個欄位的詳細說明請見[新增應用程式](/zh-hant/apps/add-an-app/)。

## 3. 啟動它

按一下應用程式的 **啟動** 按鈕（所在列上的播放圖示）。它的終端機分頁會開啟並顯示輸出。應用程式啟動期間，狀態圓點會閃動，等連接埠有了回應就會變成實心。如果 **openBrowser** 已開啟，頁面會自動開啟。

按一下應用程式的名稱只會開啟它的終端機分頁，絕不會啟動應用程式。

## 4. 停止它

按一下該列上的 **停止** 按鈕（方塊圖示）。圓點會變成灰色。

如果按下停止後仍有東西在執行，請參閱[停止與重新啟動](/zh-hant/apps/stop-and-restart/)。

## 交給代理處理

在沒有開啟任何分頁時，CLI 面板會顯示一個 **複製提示詞** 按鈕。把提示詞貼給 AI 代理，它就會找到你的應用程式並加入它們。請參閱 [AI 代理：快速開始](/zh-hant/automation/quick-start/)。

## 之後如何重新找到主視窗

- 對系統匣圖示按一下滑鼠左鍵可顯示主視窗。按滑鼠右鍵會出現一個選單，裡面有 **顯示 Moonpool** 與 **結束**。
- 預設情況下，關閉視窗就會結束 Moonpool。在設定中開啟 **關閉時縮到系統匣**，就會改為把它隱藏到系統匣並維持執行。請參閱[系統匣、關閉與最小化](/zh-hant/using/tray-and-closing/)。

## 取得說明

側邊欄頂端 **...** 選單中的 **說明** 會在獨立的視窗中開啟這份說明。它可以離線使用，而且永遠與你所執行的版本一致。
