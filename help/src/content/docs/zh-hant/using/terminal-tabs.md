每個應用程式都在 CLI 面板中它自己的終端機分頁裡執行。

## 分頁

![分頁列：Metrics Dashboard 為目前分頁（已框出），其即時記錄顯示在下方；每個分頁都有一個圓點與一個 x](../../../../assets/screenshots/hub-terminal-tab.png)

- 啟動應用程式，或在側邊欄中按一下它的名稱，都會開啟它的分頁。按一下名稱不會啟動任何東西，請參閱[應用程式狀態](/zh-hant/support/glossary/#應用程式狀態)。
- 應用程式執行時，分頁上的圓點亮起。
- 分頁上的 **x** 會關閉該分頁，但不會停止應用程式。再次按一下名稱可重新開啟分頁，它會顯示本次工作階段的記錄。

## 摺疊面板

分頁列最右側的 **x**（「隱藏 CLI 面板」）會摺疊 CLI 面板，並把視窗縮小到只剩側邊欄。終端機繼續執行，並保留各自的捲動緩衝區。

篩選方塊旁邊會出現一個箭頭，用來依之前的寬度還原面板。有更新等待安裝時，箭頭會閃動，因為更新橫幅就在這個面板裡。

## 複製與貼上

| 操作 | 結果 |
| --- | --- |
| 用滑鼠選取文字 | 放開時複製到剪貼簿，然後選取範圍會被清除。 |
| 按滑鼠中鍵 | 把剪貼簿內容貼到終端機中。 |
| **全部複製** 按鈕（右上角，滑鼠停留時出現） | 把整個捲動緩衝區複製為文字。 |

## 捲動緩衝區

每個終端機保留 10,000 行。

## 處理程序結束時

處理程序結束時，終端機會印出：

```text
[process exited]
```

分頁會保持開啟，輸出完好無缺。`[process exited]` 這一行會以你的語言顯示（繁體中文介面中為 `[處理程序已結束]`）。

## 重新啟動

**重新啟動**（或對已停止的應用程式按啟動）會在同一個分頁中開始新的一輪執行。分頁會被重建，本次工作階段中先前的輸出會從工作階段記錄重播進去。

如果該應用程式在本次工作階段中稍早已經執行過，Moonpool 會先向工作階段記錄寫入一條暗色的分隔線，這樣它會顯示在舊輸出與新一輪執行之間：

```text
---------- restarted 2026-10-05 09:14:02 ----------
```

如果新一輪執行一開始就清除畫面，先前的輸出會被推入捲動緩衝區，而不是被抹掉。

## 工作階段記錄

應用程式印出的所有內容也會寫入 `cli-output\` 下的記錄檔，每個應用程式每次 Moonpool 工作階段一個檔案。位置、保留方式以及 **在工作階段之間保留應用程式輸出記錄** 設定，請見[記錄](/zh-hant/data/logs/)。
