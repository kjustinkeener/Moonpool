## 系統匣圖示

| 操作 | 結果 |
| --- | --- |
| 按滑鼠左鍵 | 顯示主視窗（如果已最小化或隱藏，則將其還原）。 |
| 按滑鼠右鍵 | 選單中只有 **顯示 Moonpool** 與 **結束**（使用你的語言）。 |

同時執行多個 Moonpool 副本時，每個副本都有自己的系統匣圖示。提示文字會說明它是哪個副本。請參閱[可攜模式](/zh-hant/data/portable-mode/#同時執行多個副本)。

## 結束

**結束** 會結束 Moonpool，而且在 Windows 上會停止 Moonpool 啟動的每個應用程式，包括它們的子處理程序。在 Moonpool 發現它們之前就已在執行的應用程式（顯示為執行中但沒有「由 Moonpool 管理」）不會受影響。在 Linux 上，結束並不能可靠地停止已啟動的應用程式。

## 關閉與最小化

關閉按鈕預設會結束 Moonpool（`closeToTray` 為 `false`）。在設定中開啟 **關閉時縮到系統匣**，關閉視窗就會改為把它隱藏到系統匣。Moonpool 繼續執行，透過系統匣圖示或 **顯示 Moonpool** 可以把它叫回來。

**最小化到系統匣**（`minimizeToTray`，預設開啟）會在視窗最小化時把它隱藏到系統匣，並從工作列消失。關閉它則像平常一樣最小化到工作列。

## 系統匣與工作列的防鎖死機制

**在系統匣顯示** 與 **在工作列顯示** 控制系統匣圖示與工作列按鈕是否可見。至少要保留一個開啟，否則被隱藏的視窗就沒有辦法再叫出來了。只剩一個開啟時，它的核取方塊會被停用，直到你把另一個重新開啟。

## 永遠顯示在最上層

設定中的 **永遠顯示在最上層** 會讓 Moonpool 的每個視窗（主視窗、設定、關於、應用程式編輯器、佈景主題瀏覽器、安裝程式與說明）都顯示在其他視窗之上。預設為關閉。
