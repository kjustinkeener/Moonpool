## 鍵盤

| 按鍵 | 位置 | 作用 |
| --- | --- | --- |
| F5、Ctrl+R、Cmd+R | 主視窗 | 從磁碟重新載入 `apps.json`，與選單中的 **重新載入** 相同。頁面本身不會重新整理。 |
| Esc | 快顯功能表 | 關閉它。 |
| Esc | 重新命名應用程式時 | 取消重新命名。 |
| Esc | 設定、關於與應用程式編輯器視窗 | 關閉視窗（編輯器在捨棄變更前會先詢問）。 |
| Enter | 重新命名應用程式時 | 儲存新名稱。 |

## 滑鼠

| 操作 | 位置 | 作用 |
| --- | --- | --- |
| Ctrl + 滾輪 | 主視窗 | 縮放介面。 |
| 選取文字 | 終端機 | 複製並清除選取範圍。 |
| 按滑鼠中鍵 | 終端機 | 貼上。 |
| 按滑鼠右鍵 | 側邊欄中的列 | 開啟該列的選單。請參閱[側邊欄與選單](/zh-hant/using/sidebar-and-menus/)。 |

## 縮放

按住 Ctrl，在主視窗上捲動滾輪即可縮放。往上捲動是放大，往下捲動是縮小，每次滾輪事件約變化 10%。

```text
Ctrl + wheel up      zoom in
Ctrl + wheel down    zoom out
```

- 縮放範圍是 0.5 倍到 3 倍。
- 視窗會依相同的倍數調整大小，所以版面在 2 倍時和 1 倍時一樣緊湊。達到上限後，視窗就不再變大。
- 該倍數會以 `uiScale` 儲存在 `settings.json` 中，並在下次啟動時套用。儲存的視窗大小已經是縮放後的大小，所以不會再次縮放。請參閱 [settings.json](/zh-hant/data/settings-json/)。

- 縮放只作用於主視窗。設定、關於、應用程式編輯器與說明維持它們自己的大小。

`uiScale` 在設定中沒有對應的控制項，也沒有重設快速鍵。要恢復正常大小，可以往相反方向捲動相同的格數，或是結束 Moonpool，在 `settings.json` 中把 `uiScale` 設為 `1`（或刪除這個索引鍵），然後再啟動它。
