## 键盘

| 按键 | 位置 | 作用 |
| --- | --- | --- |
| F5、Ctrl+R、Cmd+R | 主窗口 | 从磁盘重新加载 `apps.json`，与菜单中的 **重新加载** 相同。页面本身不会刷新。 |
| Esc | 右键菜单 | 关闭它。 |
| Esc | 重命名应用时 | 取消重命名。 |
| Esc | 设置、关于和应用编辑器窗口 | 关闭窗口（编辑器在丢弃更改前会先询问）。 |
| Enter | 重命名应用时 | 保存新名称。 |

## 鼠标

| 操作 | 位置 | 作用 |
| --- | --- | --- |
| Ctrl + 滚轮 | 主窗口 | 缩放界面。 |
| 选中文本 | 终端 | 复制并清除选区。 |
| 鼠标中键单击 | 终端 | 粘贴。 |
| 右键单击 | 侧边栏中的行 | 打开该行的菜单。参见[侧边栏与菜单](/zh-hans/using/sidebar-and-menus/)。 |

## 缩放

按住 Ctrl，在主窗口上滚动滚轮即可缩放。向上滚动放大，向下滚动缩小，每次滚轮事件约变化 10%。

```text
Ctrl + wheel up      zoom in
Ctrl + wheel down    zoom out
```

- 缩放范围是 0.5 倍到 3 倍。
- 窗口会按相同的倍数调整大小，所以布局在 2 倍时和 1 倍时一样紧凑。达到上限后，窗口就不再增大。
- 该倍数以 `uiScale` 保存在 `settings.json` 中，并在下次启动时应用。保存的窗口大小已经是缩放后的大小，所以不会再次缩放。参见 [settings.json](/zh-hans/data/settings-json/)。

- 缩放只作用于主窗口。设置、关于、应用编辑器和帮助保持它们自己的大小。

`uiScale` 在设置中没有对应的控件，也没有重置快捷键。要恢复正常大小，可以向相反方向滚动相同的格数，或者退出 Moonpool，在 `settings.json` 中把 `uiScale` 设为 `1`（或删除这个键），然后再启动它。
