从主窗口的“...”菜单打开 **设置**。更改会在你操作时立即保存。按 Esc 关闭窗口。本页是全部设置的完整列表。每一项都保存在 `settings.json` 中所示的键下；文件本身的说明见 [settings.json](/zh-hans/data/settings-json/)。

![设置窗口：左列是开关和滑块，右列是日志选项](../../../../assets/screenshots/settings-window.png)

## 重置某个控件

右键单击任何复选框、滑块或数字字段，即可只把该项设置重置为默认值。每个控件的悬停提示里都这样写着。“语言”和“主题”选择器没有重置功能。

## 左列

| 控件 | 键 | 默认值 | 作用 |
| --- | --- | --- | --- |
| 语言 | `locale` | 自动（跟随系统） | Moonpool 自身文字所用的语言。立即生效。参见[主题、语言与透明度](/zh-hans/using/themes-and-language/)。 |
| 主题 | 无（浏览器存储） | 自动（跟随系统） | 颜色主题。该按钮会打开主题浏览器，里面有每个主题的预览；点击某个主题即可立即应用。参见[主题、语言与透明度](/zh-hans/using/themes-and-language/)。 |
| 关闭时收进托盘 | `closeToTray` | 关 | 开：关闭窗口会把 Moonpool 隐藏到托盘。关：关闭窗口即退出。 |
| 最小化时收进托盘 | `minimizeToTray` | 开 | 开：最小化会把 Moonpool 隐藏到托盘，并从任务栏消失。关：最小化到任务栏。 |
| 总在最前 | `alwaysOnTop` | 关 | 让 Moonpool 的所有窗口都显示在其他窗口之上。 |
| 在托盘中显示 | `showInTray` | 开 | 保持托盘图标可见。 |
| 在任务栏中显示 | `showInTaskbar` | 开 | 保持任务栏按钮可见。 |
| 显示 CPU/内存状态栏 | `showStatusbar` | 开 | 主窗口底部的实时 CPU 和内存条。 |
| 显示 MCP 进程 | `showMcpProcesses` | 开 | 当某个应用的 MCP 工具正在使用时，在侧边栏中把它的 MCP 进程显示为一个 MCP 子行。 |
| 背景透明度 | `transparency` | 0% | 从 0 到 90 的滑块，步长为 5。参见[主题、语言与透明度](/zh-hans/using/themes-and-language/#透明度)。 |
| 启动时检查更新 | `checkOnStartup` | 开 | 启动时到 GitHub 检查是否有新版本，找到则显示横幅。参见[更新](/zh-hans/data/updating/)。 |

### 托盘与任务栏的防锁定

**在托盘中显示** 和 **在任务栏中显示** 至少要保留一个开启，否则被隐藏的窗口就没有办法再打开了。只剩一个开启时，它的复选框会被禁用，直到你把另一个重新打开。

## 右列：日志

| 控件 | 键 | 默认值 | 作用 |
| --- | --- | --- | --- |
| 在会话之间保留应用输出日志 | `cliLogging` | 关 | 当前运行会话的终端输出始终会为它自己的标签页保留。开：旧会话的日志会保留在磁盘的 `cli-output\` 下，受保留上限约束。关：下次该应用启动时，这些日志会被删除。 |
| 每个应用的日志保留量 | `logRetentionMb` | 10 MB | 每个应用所有日志合计的上限。最小为 1。上面的开关关闭时此项被禁用。当前会话的日志计入上限，但绝不会因此被截断或删除。 |
| 把调试信息写入文件 | `debugLogging` | 关 | 把 `apps.json` 的加载、启动和错误记录到 `moonpool.log`。 |

每个日志组下方有一个显示位置的路径字段，以及两个按钮：

- **Reveal** 在文件管理器中打开该文件夹（`cli-output\` 对应 **打开 CLI 日志文件夹**，`moonpool.log` 对应 **打开日志**）。
- **Copy** 把路径放到剪贴板（**复制 CLI 日志文件夹路径**、**复制日志文件路径**）。

日志文件的格式、重启分隔线和保留规则见[日志](/zh-hans/data/logs/)。

如果某个复选框无法保存，窗口顶部会出现一条红色消息说明，并且复选框会恢复原状。

## “关于”窗口

从“...”菜单打开 **关于**。

![“关于”窗口：版本行、链接、“检查更新”和“关闭”按钮](../../../../assets/screenshots/about-window.png)

它显示：

- 版本号和构建日期。
- 项目网站、GitHub 仓库和联系地址的链接。
- **检查更新**。如果有新版本，它会下载、校验并安装，然后重启 Moonpool。否则它会报告你已是最新版本，检查失败时则报告错误。
- 对 Moonpool 所用库的致谢，以及作者。

按 Esc 关闭。“关于”窗口会实时跟随主题、透明度和语言设置。
