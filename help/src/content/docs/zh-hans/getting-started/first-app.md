## 1. 启动 Moonpool

在 Windows 上，运行 `moonpool.exe` 并点击 **安装 Moonpool**（参见[安装](/zh-hans/getting-started/install/)）。在 Linux 上，启动 AppImage 或已安装的软件包。

Moonpool 第一次运行时，会在侧边栏里放入一些示例应用（Windows 上有记事本、一个 shell、一个小型 Web 服务器和随附的仪表盘）。它们可以直接运行（Web 服务器需要 Python），你可以先试用，再编辑或删除。它还会在系统托盘中放一个图标。在 Windows 上，如果没有看到该图标，请点击任务栏右侧的 **^** 箭头。

## 2. 添加你的应用

1. 打开侧边栏顶部的 **...** 菜单，选择 **添加应用**。
2. 输入 **name**。分组一开始是 `Web apps`，可以保留，也可以换成别的。
3. 开发服务器就保持 **type** 为 `web`。
4. 把 **cwd** 设为你的项目文件夹，把 **command** 设为你用来启动它的命令，例如 `npm run dev`。
5. 把 **port** 设为它监听的端口，把 **url** 设为要打开的页面。
6. 保存。

每个字段的详细说明见[添加应用](/zh-hans/apps/add-an-app/)。

## 3. 启动它

点击应用的 **启动** 按钮（所在行上的播放图标）。它的终端标签页会打开并显示输出。应用启动期间状态圆点会闪动，一旦端口有了响应就变成实心。如果 **openBrowser** 已开启，页面会自动打开。

点击应用的名称只会打开它的终端标签页，绝不会启动应用。

## 4. 停止它

点击该行上的 **停止** 按钮（方块图标）。圆点会变灰。

如果点了停止后仍有东西在运行，参见[停止与重启](/zh-hans/apps/stop-and-restart/)。

## 让代理替你完成

在没有打开任何标签页时，CLI 面板会显示一个 **复制提示词** 按钮。把提示词粘贴给 AI 代理，它就会找到你的应用并添加它们。参见 [AI 代理：快速开始](/zh-hans/automation/quick-start/)。

## 以后如何重新找到主窗口

- 左键单击托盘图标可显示主窗口。右键单击它会出现一个菜单，里面有 **显示 Moonpool** 和 **退出**。
- 默认情况下，关闭窗口就会退出 Moonpool。在设置中打开 **关闭时收进托盘**，就会改为把它隐藏到托盘并保持运行。参见[托盘、关闭与最小化](/zh-hans/using/tray-and-closing/)。

## 获取帮助

侧边栏顶部 **...** 菜单中的 **帮助** 会在单独的窗口中打开本帮助。它可以离线使用，并且始终与你运行的版本一致。
