このページは Windows 向けです。Windows では Moonpool 自身がインストーラーを兼ねており、ダウンロードするのは `moonpool.exe` ひとつだけです。Linux にはインストールカードもポータブルの選択画面もありません。[Linux](/ja/platforms/linux/)を参照してください。

## インストール版

ダウンロードした `moonpool.exe` を実行します。初回起動時にインストールカードが表示されます。操作は 3 つあります。**Moonpool をインストール** ボタン、**デスクトップにショートカットを作成** チェックボックス (既定でオン)、そして **ポータブル版として設置** リンクです。

インストールすると、Moonpool がユーザープロファイルの `.moonpool\` 以下にコピーされ、スタートメニューのショートカット (チェックを入れた場合はデスクトップにも) が追加され、「アプリと機能」にエントリーが登録されます。その後、インストールしたコピーが起動し、このウィンドウは閉じます。ダウンロードしたファイルは元の場所に残るので、削除してかまいません。以降は、ほかのアプリと同じようにショートカットから Moonpool を起動します。

![インストールカード: Moonpool をインストールボタン、デスクトップショートカットのチェックボックス、ポータブル版として設置リンク、インストール先のパス](../../../../assets/screenshots/installer-window.png)

Moonpool に必要なものは、すべてこの 1 つのフォルダーの下にあります。プログラム、設定、同梱のヘルプです。

```text title="Installed layout"
%USERPROFILE%\.moonpool\
```

## メニューから Moonpool をインストール...

Windows では、どちらのモードでも「...」メニューに **Moonpool をインストール…** があります。同じインストールカードが開きます。ポータブル版のコピーからは、正式にインストールできます。インストール版のコピーでは **Moonpool をインストール** が無効 (「インストール済み」) になり、**ポータブル版として設置** は引き続き使えます。

## アンインストール

Windows の「アプリと機能」(インストールされているアプリ) を使うか、インストールしたコピーを `--uninstall` 付きで実行します。PATH には入っていないので、フルパスを指定します。

```powershell frame="terminal"
& "$env:USERPROFILE\.moonpool\moonpool.exe" --uninstall
```

これにより、スタートメニューとデスクトップのショートカット、レジストリのエントリー、`%USERPROFILE%\.moonpool` フォルダー全体が削除されます。**設定 (`apps.json`、設定、ログ) も含まれます。** 設定を残したい場合は、先にこのフォルダーをバックアップしてください。

```text
%USERPROFILE%\.moonpool\moonpool-config
```

実行中の Moonpool は、アンインストールの過程で停止されます。

## ポータブルモード

USB メモリーや移動可能なフォルダーで使いたいですか? インストールカードで **ポータブル版として設置** をクリックし、フォルダーを選びます。[ポータブルモード](/ja/data/portable-mode/)を参照してください。
