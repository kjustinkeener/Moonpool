## 1. Moonpool を起動する

Windows では `moonpool.exe` を実行し、**Moonpool をインストール** をクリックします ([インストール](/ja/getting-started/install/)を参照)。Linux では、AppImage またはインストールしたパッケージを起動します。

Moonpool を初めて実行すると、サイドバーにサンプルアプリが追加されます (Windows ではメモ帳、シェル、小さな Web サーバー、同梱のダッシュボード)。これらはそのまま動作するので (Web サーバーには Python が必要です)、試したあとで編集や削除ができます。システムトレイにもアイコンが表示されます。Windows でアイコンが見当たらない場合は、タスクバー右側の **^** 矢印をクリックしてください。

## 2. アプリを追加する

1. サイドバー上部の **...** メニューを開き、**アプリを追加** を選びます。
2. **名前** を入力します。グループの初期値は `Web apps` です。そのままにするか、別のグループを選びます。
3. 開発サーバーなら **type** は `web` のままにします。
4. **cwd** にプロジェクトのフォルダーを、**command** に起動するときに入力するコマンド (例: `npm run dev`) を設定します。
5. **port** にアプリが待ち受けるポートを、**url** に開くページを設定します。
6. 保存します。

各フィールドの詳細は[アプリを追加する](/ja/apps/add-an-app/)にあります。

## 3. 起動する

アプリの **起動** ボタン (行にある再生アイコン) をクリックします。そのアプリのターミナルタブが開き、出力が表示されます。起動中はステータスの点が点滅し、ポートが応答すると点灯したままになります。**openBrowser** がオンなら、ページが開きます。

アプリの名前をクリックすると、ターミナルタブが開くだけです。アプリは起動しません。

## 4. 停止する

行の **停止** ボタン (四角) をクリックします。点が灰色になります。

停止したあとも何かが動き続ける場合は、[停止と再起動](/ja/apps/stop-and-restart/)を参照してください。

## エージェントに任せる

タブを何も開いていないとき、CLI パネルに **プロンプトをコピー** ボタンが表示されます。そのプロンプトを AI エージェントに貼り付けると、エージェントがアプリを見つけて追加します。[AI エージェント: クイックスタート](/ja/automation/quick-start/)を参照してください。

## あとからハブを開くには

- トレイアイコンを左クリックすると、ハブが表示されます。右クリックすると、**Moonpool を表示** と **終了** のメニューが開きます。
- 既定では、ウィンドウを閉じると Moonpool は終了します。設定で **閉じたらトレイに格納** をオンにすると、閉じたときにトレイへ隠れ、実行が続きます。[トレイ、閉じる、最小化](/ja/using/tray-and-closing/)を参照してください。

## ヘルプを見る

サイドバー上部の **...** メニューにある **ヘルプ** を選ぶと、このヘルプが専用のウィンドウで開きます。オフラインで使え、実行しているバージョンと常に一致します。
