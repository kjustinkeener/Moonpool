## アプリ

| 用語 | 意味 |
| --- | --- |
| アプリ(app) | Moonpool が管理する 1 つの対象。開発サーバー、デスクトップアプリ、ページ、コマンドのいずれかです。 |
| エントリ(entry) | `apps.json` にあるアプリのレコード。JSON について話すときだけ使います。 |
| アプリ行(app row) | サイドバーにあるアプリの行。状態のドットと操作ボタンが付いています。 |
| グループ(group) | アプリが一覧表示されるサイドバーの見出し。`group` フィールドで決まります。 |
| タイプ(type) | `web`、`desktop`、`static`、`cli` のいずれか。どのフィールドが重要かを決めます。[アプリのタイプ](/ja/apps/types/)を参照してください。 |
| ID(id) | アプリの恒久的なキー。ファイル名、コマンド、エージェントのツールで使われます。[ID](/ja/apps/apps-json/#id)を参照してください。 |

## アプリの状態

| 状態 | 意味 |
| --- | --- |
| 起動中(starting) | Moonpool がアプリを起動したものの、まだ立ち上がりを確認できていない状態。ドットが脈動します。 |
| 実行中(Running) | その `port` が応答している、`processName` のプロセスが存在する、またはどちらも設定されていなければ、Moonpool が起動したターミナルがまだ生きている状態。ドットは塗りつぶされます。[実行中かどうかの判定](/ja/apps/types/#実行中の判定方法)を参照してください。 |
| 停止中(stopped) | 上のいずれにも当てはまらない状態。ドットは灰色です。 |
| managed | 今回のセッションで Moonpool が起動したもの(Moonpool による管理下)。managed でない実行中のアプリは別の方法で起動されたもので、終了しても Moonpool はそのままにします。 |

ターミナルタブと実行中のアプリは別のものです。アプリの名前をクリックすると、そのターミナルタブが開くだけで、アプリは起動しません。タブを閉じても、アプリは停止しません。

## ウィンドウと各部

| 用語 | 意味 |
| --- | --- |
| ハブ(hub) | 常駐する Moonpool プロセスとそのメインウィンドウ。ツール名では「launcher」と呼ばれます。 |
| ハブウィンドウ(hub window) | メインウィンドウ。左にサイドバー、右に CLI ペインがあります。 |
| トレイ(tray) | システムトレイのアイコンとそのメニュー(**Moonpool を表示**、**終了**)。 |
| サイドバー(sidebar) | ハブウィンドウの左側。フィルターボックス、**...** メニュー、アプリ行があります。 |
| CLI ペイン(CLI pane) | ハブウィンドウの右側で、ターミナルタブが入っています。 |
| ターミナルタブ(terminal tab) | CLI ペイン内の、1 つのアプリのターミナル。 |
| MCP の子行(MCP sub-row) | アプリの下に表示される薄い行で、そのアプリ自身の `<exe> mcp` ヘルパープロセスを示します。 |
| アプリエディター(app editor) | 「アプリを追加」と「アプリを編集」のダイアログ。 |

## ファイルとフォルダー

| 用語 | 意味 |
| --- | --- |
| 設定フォルダー(config folder) | `apps.json` と Moonpool のそのほかのファイルがあるフォルダー。`{MP_DATA}` トークンです。[設定の保存場所](/ja/apps/apps-json/#設定の保存場所)を参照してください。 |
| `{MP_HOME}` | Moonpool のフォルダー。インストール版では `%USERPROFILE%\.moonpool`、ポータブル版ではその `.moonpool\` フォルダー、Linux では設定フォルダーです。 |
| セッション(session) | ハブの 1 回の実行。起動から終了までです。 |
| セッションログ(session log) | 1 セッションの間にアプリが出力したすべてを保持するファイル。`cli-output\` の下にあります。[ログ](/ja/data/logs/)を参照してください。 |
| `moonpool.log` | Moonpool 自身のデバッグログ。**デバッグ情報をファイルに記録**がオンのときだけ書き込まれます。 |
| ダンプ(dump) | `dump` 動詞で作る、セッションログのプレーンテキストのコピー。 |
| スナップショット(snapshot) | `apps.json.history\` にある、正常な `apps.json` のコピー。[バックアップと復旧](/ja/data/backup-and-recovery/)を参照してください。 |

## モード

| 用語 | 意味 |
| --- | --- |
| インストール版(installed) | `%USERPROFILE%\.moonpool` にある Moonpool。スタートメニューのショートカットと「アプリと機能」の項目があります。Windows のみです。 |
| ポータブル版(portable) | 自分で選んだ `.moonpool\` フォルダーにある Moonpool。`moonpool.portable` ファイルが目印です。[ポータブルモード](/ja/data/portable-mode/)を参照してください。 |
| コピー(copy) | インストール版かポータブル版かを問わず、1 つの Moonpool フォルダー。コピーはそれぞれ独立して動作します。 |

## 停止と自動化

| 用語 | 意味 |
| --- | --- |
| `killMode` | 停止がアプリのターミナルを終了させた後に行う追加の手順。[停止と再起動](/ja/apps/stop-and-restart/)を参照してください。 |
| `stopCommand` | `killMode` が `command` のときに、停止が実行するコマンド。 |
| `processName` | Moonpool が監視するプロセス名。`processName` モードでは、これを終了させる対象にもなります。 |
| 制御チャネル(control channel) | ハブが応答する名前付きパイプ(Windows)または Unix ソケット(Linux)。[制御動詞](/ja/automation/control-verbs/)を参照してください。 |
| 動詞(verb) | `launch` や `reload` のようなコマンドの語。コマンドラインまたは制御チャネルで指定します。 |
| チケット(ticket) | `--ticket` で付けるキー。`state.json` からコマンドの結果を読み取るために使います。 |
| トークン(token) | 設定の書き込みに付ける必要がある、`apps.json` のバージョンスタンプ。 |
| MCP ヘルパー(shim)(MCP helper) | AI ホストがアプリ自身のツールに接続するために起動する `<exe> mcp` プロセス。 |
