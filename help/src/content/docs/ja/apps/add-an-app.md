title: "Moonpool にアプリや開発サーバーを追加する"
description: "起動コマンド、作業フォルダー、環境変数を指定してローカルアプリや開発サーバーを登録すると、Moonpool が代わりに起動、停止、監視します。"
---

Moonpool の各アプリは、起動コマンド、作業フォルダー、省略可能な環境変数をまとめた 1 つのエントリーです。Moonpool はそのコマンドを、専用の管理されたターミナルで実行します。

## アプリを追加する

1. サイドバー上部の **...** メニューを開き、**アプリを追加** を選びます。
2. **name** を入力し、**group** を選びます。
3. **type** を選びます: `web` (ポートで待ち受けるサーバー)、`desktop` (ネイティブアプリ)、`static` (ページ)、`cli` (コマンド)。
4. **command** と、それを実行する **cwd** を設定します。
5. type に必要な項目を入力します。web なら **port** と **url**、desktop なら **processName**、static なら **url** です。`url` だけの `static` アプリには、**command** も **cwd** も不要です。
6. 保存します。アプリがサイドバーに表示されます。**起動** ボタンで起動します。

![アプリエディターの type の選択 (1) と port 欄 (2)。その間に cwd と command がある](../../../../assets/screenshots/edit-app-type-and-port.png)

1. **type** の選択。ヒントに、その type の動作方法が表示されます。
2. **port** 欄。`web` アプリが使います。

結果として、`apps.json` に次のようなエントリーが 1 つできます。

```json title="apps.json"
{
  "id": "my-api",
  "name": "My API",
  "group": "Dev",
  "type": "web",
  "command": "npm run dev",
  "cwd": "C:\\code\\my-api",
  "port": 3000,
  "url": "http://localhost:3000"
}
```

アプリの名前をクリックしても、ターミナルタブが開くだけです。[アプリの状態](/ja/support/glossary/#アプリの状態)を参照してください。

## アプリエディター

- **Group。** 一覧からグループを選ぶか、**+ 新しいグループ...** を選んで名前を入力します。**一覧に戻る** で一覧に戻ります。空のグループは `Apps` として保存されます。
- **薄く表示された項目** は、選んだ type では使われません。それでも保存はされます。
- **名前なしで保存** すると、`name は必須です。` と表示されます。
- 保存していない変更がある状態で **Esc** を押すかエディターを閉じると、「変更を破棄しますか?」と確認されます。
- あとからアプリを変更するには、行の鉛筆を使うか、右クリックして **編集** を選びます。

## 手作業で編集する

同じメニューの **apps.json を編集** を選び、ファイルを保存してから、**再読み込み** を選びます。形式、検証ルール、復旧の方法は[設定の概要](/ja/apps/apps-json/)にあります。
