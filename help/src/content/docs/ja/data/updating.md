Moonpool は自分自身を更新します。別途ダウンロードするインストーラーはなく、ウィザードを順にクリックする必要もありません。

## 更新が届く仕組み

Moonpool は、プロジェクトの GitHub Releases から `update.json`(Linux では `linux-update.json`)を取得してバージョンを比較し、厳密に新しいバージョンだけを提案します。確認が行われるのは次のときです。

- 起動時。ただし、[設定](/ja/using/settings/)で**起動時に更新を確認**がオフの場合を除きます。
- 「このアプリについて」ウィンドウで**更新を確認**を押したとき。このボタンは、新しいバージョンがあればただちにインストールして Moonpool を再起動します。なければ最新バージョンであることを伝え、エラーがあればそれを表示します。

「このアプリについて」ウィンドウには、名前の下に実行中のバージョンが表示されます。

![「このアプリについて」ウィンドウの上部: ロゴ、名前 (1)、その下のバージョンの行](../../../../assets/screenshots/about-header.png)

1. 名前です。その下の行は、バージョンとビルド日です。

ダウンロードしたものはすべて、適用される前に Moonpool の minisign 署名鍵で検証されます。そのため、改ざんされたり破損したりしたダウンロードは拒否されます。Moonpool が古いバージョンをインストールすることはありません。

## 更新バナー

起動時に更新が見つかると、ハブの空の画面にバナーとして表示されます。

```text
Moonpool {version} が利用できます (現在は {current})。
```

バナーが表示されるのは、アプリのタブが 1 つも開いておらず、CLI ペインが展開されているときだけです。ペインが折りたたまれている場合は、代わりにフィルターボックスの横のシェブロンが脈動します。タブが開いているときは、何の表示もありません。バナーを見るには、すべてのタブを閉じる(そしてペインを展開する)か、「このアプリについて」ウィンドウの**更新を確認**を使ってください。

**ダウンロードしてインストール**をクリックすると、Moonpool は自分自身を置き換えて再起動します。バナーを閉じるには、x を押します。

## ポータブル版

ポータブル版は、自身の `.moonpool\` フォルダー内の `moonpool.exe` を、同じ方法で更新します。コピーごとに、確認と更新を独立して行います。フォルダーは書き込み可能である必要があるため、読み取り専用の USB メモリや共有上のコピーは、自分では更新できません。新しい `moonpool.exe` を手作業で上書きコピーしてください。

## Linux

自己更新できるのは AppImage だけです。AppImage ファイルをその場で置き換えるため、書き込み可能なフォルダーに置いてください。`.deb` または RPM でインストールしたものは、パッケージマネージャーで更新します。Moonpool から更新しようとすると、次のメッセージで失敗します。

```text
automatic updates are available for the AppImage only; update the .deb or RPM with your package manager
```

[Linux](/ja/platforms/linux/#更新)を参照してください。

## 更新に失敗したとき

バナーに理由が表示され、ボタンが再び使えるようになるので、再試行できます。

```text
更新に失敗しました: <error>
```

| エラーに含まれる文字列 | 考えられる原因 | 対処 |
| --- | --- | --- |
| `download failed` | 接続がない、プロキシ、または GitHub によるリクエスト制限 | しばらく待ってから再試行するか、手作業で更新します。 |
| `signature verification FAILED - refusing to install` | ダウンロードが破損しているか、改変された | 再試行します。失敗し続ける場合は、Releases ページから手作業で更新します。 |
| `rename self aside` または `write new exe` | フォルダーが読み取り専用であるか、ウイルス対策ソフトがファイルを保持している | フォルダーを書き込み可能にするか、ウイルス対策ソフトで `moonpool.exe` を許可してから、再試行します。 |
| `refusing to install ... not newer than current` | 提示されたバージョンが新しくない | 対処は不要です。 |

### 手作業で更新する

Moonpool を終了し、プロジェクトの [Releases ページ](https://github.com/kjustinkeener/Moonpool/releases)から `moonpool.exe` をダウンロードして、古いものに上書きコピーします。インストール版では `%USERPROFILE%\.moonpool\moonpool.exe`、ポータブル版では `.moonpool\` フォルダー内のものです。設定フォルダーには手を触れません。Linux では、AppImage を置き換えるか、パッケージマネージャーを使います。

## ヘルプも更新されます

このヘルプは Moonpool の中に同梱されているため、プログラムの更新のたびに、対応するヘルプも一緒に届きます。オフラインのコピーは、常に実行中のバージョンと一致します。
