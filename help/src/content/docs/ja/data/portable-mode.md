---

ポータブルモードでは、Moonpool とそれが書き込むものすべてを 1 つの `.moonpool\` フォルダーにまとめます。USB メモリで持ち運んだり、同期フォルダーに置いたりして、どの PC でも実行できます。

## 仕組み

ポータブル版としてインストールすると、Moonpool は選んだ場所の中に `.moonpool\` フォルダーを作ります。このフォルダーには、プログラム、設定、ヘルプの内容が入ります。Windows の AppData には何も書き込まれないため、フォルダーを移動またはコピーすれば、環境全体がそのまま移ります。

```text
<chosen location>\.moonpool\
```

## インストール版との違い

| | インストール版 | ポータブル版 |
| --- | --- | --- |
| プログラム | `%USERPROFILE%\.moonpool\moonpool.exe` | `<chosen location>\.moonpool\moonpool.exe` |
| 設定フォルダー | `%USERPROFILE%\.moonpool\moonpool-config\` | `<chosen location>\.moonpool\moonpool-config\` |
| ウィンドウのブラウザープロファイル、ウィンドウのサイズと位置 | 設定フォルダー内 | 設定フォルダー内。そのため、これらも一緒に持ち運べます |
| スタートメニュー、デスクトップのショートカット、「アプリと機能」の項目 | あり | なし |
| 更新 | 自分の exe を置き換える | 同じ。`.moonpool\` フォルダー内で行われます。[更新](/ja/data/updating/#ポータブル版)を参照してください。 |
| 削除 | 「アプリと機能」または `--uninstall` | フォルダーを削除 |

どちらのモードも、Windows の AppData には書き込みません。

### 同期フォルダー

ポータブル版は(OneDrive や Dropbox などの)同期フォルダーに置けますが、一度に 1 台の PC でだけ実行してください。Moonpool は数秒ごとに `state.json` を書き込み、アプリの実行に合わせてログも書き込みます。そのため、2 台の PC で同じフォルダーを実行すると同じファイルを取り合うことになり、同期の競合で `apps.json` が壊れることがあります。別の PC で起動する前に、一方の PC で終了してください。

## 複数のコピーを同時に

Moonpool が実行されるのはフォルダーごとに 1 つです。インストール版と、それぞれ別のフォルダーにある任意の数のポータブル版は同時に実行でき、それぞれが完全に独立しています。アプリ、トレイアイコン、ウィンドウ、設定、ログ、[制御チャネル](/ja/automation/control-verbs/)はすべて別々です。

- トレイのツールチップとタスクバーの名前で、どのコピーかがわかります。インストール版は `Moonpool`、ポータブル版は `Moonpool (<folder>)` で、`<folder>` は選んだフォルダー(`.moonpool\` を含むフォルダー)です。
- 同じコピーを 2 回起動すると、もう 1 つ開く代わりに、そのウィンドウが前面に戻ります。別のコピーを起動すると、そのコピーが開きます。
- AI エージェントに複数のコピーを使わせるには、それぞれを別の名前で登録します。[MCP のセットアップ](/ja/automation/mcp-setup/#複数の-moonpool)を参照してください。
- ポータブルフォルダーを移動または名前変更すると、新しい識別情報(新しい制御チャネル名)になります。移動する前に終了してください。
- コピー同士は、互いのアプリを知りません。同じポートで同じサーバーを起動する 2 つのコピーは、やはり衝突します。また、プロセス名またはポートで動作する停止は、別のコピーが起動したものを終了させることがあります。[停止と再起動](/ja/apps/stop-and-restart/#複数の-moonpool-や自分で起動したプロセス)を参照してください。

## アプリも一緒に持ち運ぶ

アプリのパスに `{MP_HOME}` トークンを使うと、1 台のマシン上の固定された場所ではなく、ポータブルフォルダーの内側を指すようになります。ポータブル版では、`{MP_HOME}` は `moonpool.exe` があるフォルダーで、それは選んだフォルダーではなく `.moonpool\` フォルダー自体です。

```json title="apps.json"
{ "cwd": "{MP_HOME}/my-app" }
```

ここでは、`{MP_HOME}/my-app` は `<chosen location>\.moonpool\my-app` になります。`./` で始まるパスも同じように基準が決まります。トークンと `./` のパスは、インストール版の Moonpool でも使えます。パスの解決のしかたについては、[パスと環境変数](/ja/apps/paths-and-environment/)を参照してください。

## インストーラーからポータブル版を選ぶ

ポータブルモードは、インストーラーのカードから設定します。カードには **Moonpool をインストール**と並んで**ポータブル版として設置**が表示されます。

![インストールカード: メインの Moonpool をインストールボタンの下に、ポータブル版として設置のリンクがあります](../../../../assets/screenshots/installer-window.png)

フォルダーを選ぶと、Moonpool はそこに `.moonpool\` フォルダーを作り、自分自身をコピーして、新しいコピーを新規の設定で起動します。

このカードは、インストール版でもポータブル版でも、「...」メニューの **Moonpool をインストール…**からも開けます。そこから**ポータブル版として設置**を使うと、実行中の Moonpool が終了し、その代わりに新しいポータブル版が起動します。元の Moonpool は元の場所に残るので、後でまた起動できます。

ポータブル版は新規の状態で始まり、既存のアプリはコピーされません。それらを移すには、ポータブル版を終了して、`apps.json` を手作業でコピーします。

| | パス |
| --- | --- |
| コピー元(インストール版) | `%USERPROFILE%\.moonpool\moonpool-config\apps.json` |
| コピー先(ポータブル版) | `<chosen location>\.moonpool\moonpool-config\apps.json` |

絶対パスを使っているエントリは、同じ PC では引き続き動作しますが、持ち運べません。「アプリを編集」ダイアログでは、それらに「持ち運び不可」と表示されます。

## Moonpool がポータブルだと判断する方法

`moonpool.exe` の隣に `moonpool.portable` というファイルがある間、そのコピーはポータブルです。ほかに印はなく、Windows に登録されるものもありません。

ポータブル版を削除するには、終了してから `.moonpool\` フォルダーを削除します。`--uninstall` が削除するのはインストール版の Moonpool だけで、ポータブル版は削除しません。
