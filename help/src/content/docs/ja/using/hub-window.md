1. 実行中のアプリのうちの 2 つ: 再生ではなく、点灯したステータスの点と停止ボタンが表示されています。
2. タブの列: 開いたアプリごとに 1 つのタブがあり、アクティブなタブが強調表示されます。
3. アクティブなアプリのリアルタイム出力。
4. CPU とメモリのステータスバー。

## レイアウト

| 領域 | 内容 |
| --- | --- |
| タイトルバー | 最小化、最大化、閉じる。 |
| サイドバー | 絞り込みボックス、**...** メニュー、`group` ごとにまとめたアプリ。[サイドバーとメニュー](/ja/using/sidebar-and-menus/)を参照してください。 |
| CLI パネル | 開いたアプリごとに 1 つのターミナルタブ。[ターミナルタブ](/ja/using/terminal-tabs/)を参照してください。 |
| ステータスバー | 下部に表示される、CPU とメモリのリアルタイム表示。 |

サイドバーと CLI パネルの間の境界線をドラッグすると、サイドバーの幅を変更できます。

## ステータスバー

![ステータスバー: 左にコアごとの CPU バー、右にメモリバー](../../../../assets/screenshots/status-bar.png)

ステータスバーには、CPU のコアごとに細いバーが 1 本ずつ表示され (カーソルを合わせると「コアごとの CPU 使用率」と表示されます)、続いて `使用量/合計 GB` というラベル付きのメモリバーが表示されます。設定の **CPU/メモリのステータスバーを表示** (`showStatusbar`。[設定ウィンドウ](/ja/using/settings/)を参照) で非表示にできます。変更はすぐに反映されます。

## ... メニュー

絞り込みボックスの左にある **...** ボタンで、メニューが開きます。

![サイドバー上部の ... メニューボタン (1) とアプリを絞り込むボックス (2)](../../../../assets/screenshots/sidebar-filter-and-menu.png)

1. **...** メニューボタン。
2. **アプリを絞り込む...** ボックス。

| 項目 | 動作 |
| --- | --- |
| アプリを追加 | アプリエディターを開きます。[アプリを追加する](/ja/apps/add-an-app/)を参照してください。 |
| apps.json を編集 | `apps.json` を既定のエディターで開き、手作業で編集できます。 |
| 再読み込み | `apps.json` をディスクから再び読み込みます (F5 でも可。[ショートカットとズーム](/ja/using/keyboard-shortcuts/)を参照)。 |
| 設定 | 設定ウィンドウを開きます。 |
| ヘルプ | このヘルプを開きます。 |

| Moonpool をインストール… | Windows のみ。インストーラーのウィンドウを開き、アプリのインストールやポータブル版の作成ができます。[インストール](/ja/getting-started/install/)と[ポータブルモード](/ja/data/portable-mode/)を参照してください。 |

### ポート競合の警告

`apps.json` の 2 つのアプリが同じ `port` を使っていると、メニューの下部に警告の行が表示されます。たとえば次のようになります。

```text
port 3000: App A / App B
```

カーソルを合わせると、全文が表示されます。`apps.json` かアプリエディターで競合を解消すると、ポートを共有するものがなくなった時点で、この行は消えます。

## apps.json にエラーがあるとき

再読み込み (または F5) で `apps.json` が解析または検証できなくなっていると分かった場合、Moonpool はそれまでの一覧を保持します。サイドバーの上部にバナーが表示され、「apps.json にエラーがあります。最後に読み込めた一覧を表示しています。」というメッセージに続けてエラー内容が示されます (全文はカーソルを合わせると表示されます)。下の一覧は薄く表示されますが、操作はできるので、いつもどおりアプリを起動、停止できます。バナーの **apps.json を編集** でファイルが開きます。修正して **再読み込み** を選ぶと、バナーは消えます。

ファイルが再び読み込めるようになるまで、Moonpool はアプリエディター、名前の変更、削除、アイコンの設定による変更を保存しません。そのため、不正なファイルが上書きされることはありません。

Moonpool の起動時にすでにファイルが壊れている場合は、保持できる以前の一覧がありません。バナーには、アプリが読み込まれていないことが表示され、サイドバーは空になります。ファイルを修正して再読み込みするか、最近の正常なコピーに戻してください ([ファイルが不正なとき](/ja/apps/apps-json/#ファイルが不正なとき)を参照)。

## 空の画面

タブを何も開いていないと、CLI パネルに「左からアプリを選ぶと起動できます。」と表示されます。タブが開いていない間だけ表示されるものが、ほかに 2 つあります。

- **更新バナー**: 起動時に新しいバージョンが見つかったときに表示されます。[更新](/ja/data/updating/)を参照してください。
- **プロンプトをコピー**: アプリの設定を AI エージェントに任せるための、用意されたプロンプトです。[AI エージェント: クイックスタート](/ja/automation/quick-start/#プロンプトをコピー)を参照してください。

トレイアイコン、閉じる、最小化、終了、常に手前に表示については、[トレイ、閉じる、最小化](/ja/using/tray-and-closing/)にあります。

## サイズ、位置、最大化の状態

Moonpool は、ハブウィンドウのサイズ、位置、最大化の状態を、次回以降の起動でも記憶します。初回起動時は 1200x780 で、位置は Windows が決めた場所に開きます。

保存された位置が、接続中のどのディスプレイにも収まらなくなった場合 (たとえばモニターを取り外したとき) は、位置は無視され、保存されたサイズが既定の位置で使われます。ファイルは設定フォルダーにある `window-state.json` です ([設定の保存場所](/ja/apps/apps-json/#設定の保存場所)を参照)。

サイドバーの幅と、CLI パネルが折りたたまれているかどうかも記憶されます。
