テーマ、言語、透明度は、[設定ウィンドウ](/ja/using/settings/)で設定します。3 つとも、開いているすべての Moonpool ウィンドウにすぐに反映されます。

![設定の上部にある言語 (1) とテーマ (2) の選択](../../../../assets/screenshots/settings-language-theme.png)

1. 言語の選択。
2. テーマのボタン。現在のテーマの名前が表示され、テーマブラウザーが開きます。

## テーマ

テーマブラウザーは独立したウィンドウです。テーマごとに 1 枚のプレビューカードがあり、それぞれがそのテーマ自身の色 (テキスト、パネル、入力欄、ボタン、ステータスの点、ゲージのグラデーション、16 色のターミナルパレット) で描かれています。カードは、基本、ネオン、暖色、寒色、グリーン、ニュートラル、ライト、ブラッシュ、ビビッド、ライトパステル、パステルにグループ分けされています。カードをクリックすると適用されます。開いているすべての Moonpool ウィンドウが一度に切り替わり、選択が保存されます。ウィンドウは開いたままなので比較でき、Esc で閉じます。

テーマは 68 種類と自動があり、その約半数がライトテーマです。テーマ名は固有名詞なので翻訳されません。翻訳されるのは、自動 (システム)、ダーク、ライトだけです。

**自動 (システム)** は、オペレーティングシステムのライト / ダークの設定に従い、OS が切り替わるとリアルタイムで切り替わります。それ以外を選ぶと固定されます。ターミナルの 16 の ANSI カラーも、テーマに従います。

以前のバージョンで保存したテーマは保持されます。Moonpool がもう知らない名前で保存されていた場合は、自動に戻ります。以前とラベルが違うものもあります (たとえば Matrix は Terminal、Nord は Arctic、Dracula は Nocturne、Gruvbox は Retro、Solarized は Solar と表示されます)。保存された選択そのものは変わりません。

テーマは、`settings.json` ではなく、WebView の `localStorage` に保存されます。ストレージが利用できない場合は、自動に戻ります。

```text
localStorage key: moonpool.theme
```

## 言語

自動は、OS の言語に従います。それ以外は、14 言語から選びます。それぞれが、その言語自身の表記で表示されます。

```text
English, Deutsch, Español, Français, Italiano, 日本語, 한국어, Nederlands, Polski,
Português (Brasil), Русский, Türkçe, 简体中文, 繁體中文
```

選択はハブとほかのウィンドウにすぐに反映されます。選択は `settings.json` の `locale` として保存されます。

## 透明度

**背景の透明度** は、ウィンドウの背景を透かします。0% (不透明) から 90% まで設定できます。

- ウィンドウの上にポインターを置くと、そのウィンドウはすぐに完全な不透明になります。ポインターが離れると、約 2 秒かけて、設定した値まで戻ります。
- ターミナルは独自の色を重ねず、同じ色合いに従います。
- 各ウィンドウ (ハブ、設定、情報、アプリエディター、テーマブラウザー) は、それぞれ自分でこの設定を適用します。スライダーをドラッグすると、設定がほかのウィンドウをリアルタイムで更新します。

## UI の倍率

Ctrl + マウスホイールで、インターフェース全体をズームします。キーボードでのズームはありません。[ショートカットとズーム](/ja/using/keyboard-shortcuts/)を参照してください。
