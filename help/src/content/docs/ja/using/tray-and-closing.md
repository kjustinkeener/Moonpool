## トレイアイコン

| 操作 | 結果 |
| --- | --- |
| 左クリック | ハブウィンドウを表示します (最小化または非表示の場合は元に戻します)。 |
| 右クリック | **Moonpool を表示** と **終了** だけのメニュー (お使いの言語で表示されます)。 |

複数の Moonpool のコピーが動いている場合、それぞれが専用のトレイアイコンを持ちます。ツールチップに、どのコピーかが表示されます。[ポータブルモード](/ja/data/portable-mode/#複数のコピーを同時に)を参照してください。

## 終了

**終了** は Moonpool を終了し、Windows では、Moonpool が起動したすべてのアプリを、その子プロセスも含めて停止します。Moonpool が認識する前からすでに動いていたアプリ (実行中と表示されるが「managed by Moonpool」がないもの) には、何もしません。Linux では、終了しても、起動したアプリが確実に停止するとは限りません。

## 閉じる、最小化

閉じるボタンは、既定では Moonpool を終了します (`closeToTray` は `false` です)。設定で **閉じたらトレイに格納** をオンにすると、閉じたときにウィンドウがトレイに隠れるようになります。Moonpool は動き続け、トレイアイコンか **Moonpool を表示** で元に戻せます。

**最小化したらトレイに格納** (`minimizeToTray`、既定はオン) は、最小化したときにウィンドウをトレイに隠し、タスクバーから消します。オフにすると、いつもどおりタスクバーに最小化されます。

![設定: 閉じたらトレイに格納と最小化したらトレイに格納 (1)、および背景の透明度スライダー (2)](../../../../assets/screenshots/settings-tray-and-transparency.png)

1. **閉じたらトレイに格納** と **最小化したらトレイに格納**。
2. **背景の透明度**。[テーマ、言語、透明度](/ja/using/themes-and-language/#透明度)を参照してください。

## トレイとタスクバーのロックアウト防止

**トレイに表示** と **タスクバーに表示** は、トレイアイコンとタスクバーボタンを表示するかどうかを制御します。少なくとも一方はオンのままにしておく必要があります。そうしないと、隠れたウィンドウを戻す手段がなくなります。一方だけがオンのとき、そのチェックボックスは、もう一方をオンに戻すまで無効になります。

## 常に手前に表示

設定の **常に手前に表示** は、Moonpool のすべてのウィンドウ (ハブ、設定、情報、アプリエディター、テーマブラウザー、インストーラー、ヘルプ) を、ほかのウィンドウより手前に保ちます。既定ではオフです。
