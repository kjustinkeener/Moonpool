各アプリは、CLI パネルの専用ターミナルタブで実行されます。

## タブ

![Metrics Dashboard がアクティブ (枠線で強調) で、その下にリアルタイムのログが表示されたタブの列。各タブには点と x がある](../../../../assets/screenshots/hub-terminal-tab.png)

- アプリを起動するか、サイドバーでその名前をクリックすると、そのタブが開きます。名前をクリックしても何も起動しません。[アプリの状態](/ja/support/glossary/#アプリの状態)を参照してください。
- アプリが実行中の間は、タブの点が点灯します。
- タブの **x** はタブを閉じます。アプリは停止しません。名前を再びクリックするとタブが開き直り、このセッションのログが表示されます。

## パネルを折りたたむ

タブの列の右端にある **x** (「CLI パネルを隠す」) で、CLI パネルが折りたたまれ、ウィンドウはサイドバーだけの幅に縮みます。ターミナルは動き続け、スクロールバックも保たれます。

絞り込みボックスの横に山形のボタンが現れ、押すと、パネルが以前の幅で元に戻ります。更新バナーはこのパネルの中にあるため、更新が待機中のときは、この山形が点滅します。

## コピーと貼り付け

| 操作 | 結果 |
| --- | --- |
| マウスでテキストを選択 | ボタンを離すとクリップボードにコピーされ、選択が解除されます。 |
| 中クリック | クリップボードの内容をターミナルに貼り付けます。 |
| **すべてコピー** ボタン (右上、ホバー時に表示) | スクロールバック全体をテキストとしてコピーします。 |

## スクロールバック

各ターミナルは 10,000 行を保持します。

## プロセスが終了したとき

プロセスが終了すると、ターミナルに次のように出力されます。

```text
[process exited]
```

タブは開いたままで、出力もそのまま残ります。`[process exited]` の行は、お使いの言語で表示されます (日本語では `[プロセスが終了しました]` です)。

## 再起動

**再起動** (停止中のアプリでは起動) は、同じタブで新しい実行を開始します。タブは作り直され、このセッションのそれまでの出力が、セッションログから再生されます。

アプリがすでにこのセッションの前半で実行されていた場合、Moonpool はまずセッションログに薄い区切り線を書き込みます。これにより、以前の出力と新しい実行の間に区切りが表示されます。

```text
---------- restarted 2026-10-05 09:14:02 ----------
```

新しい実行が画面のクリアから始まる場合は、以前の出力は消されず、スクロールバックに押し出されます。

## セッションログ

アプリが出力したものはすべて、`cli-output\` 以下のログファイルにも書き込まれます。1 つの Moonpool セッションにつき、アプリごとに 1 ファイルです。保存場所、保持、**アプリの出力ログをセッション間で保持** の設定は、[ログ](/ja/data/logs/)にあります。
