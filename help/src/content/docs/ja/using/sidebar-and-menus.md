サイドバーには、`apps.json` のすべてのアプリが、各アプリの `group` フィールドごとにまとめて表示されます。[アプリのフィールド](/ja/apps/fields/)を参照してください。

## 行

各行には、ステータスの点、アプリのアイコン (アイコンがなければ種類を表す図形)、名前、設定されていればポート (`:3000`)、そして操作ボタンが表示されます。

| 点 | 意味 |
| --- | --- |
| 点灯 | 実行中 |
| 点滅 | 起動中: Moonpool がアプリを起動したものの、まだ立ち上がりが確認できていません |
| 灰色 | 停止中 |

点にカーソルを合わせると、状態を表す言葉が表示されます。

![実行中の Web アプリ 2 つを枠線で強調したサイドバー: 点灯した点と停止ボタン](../../../../assets/screenshots/sidebar-running-narrow.png)

1. 実行中のアプリ 2 つ。点が点灯し、起動の代わりに停止 (四角) が表示されています。

| 操作 | 動作 |
| --- | --- |
| 鉛筆 | アプリを編集します。 |
| 再起動 | 停止して、再び起動します。停止中のアプリでは、単に起動します。 |
| 起動 (再生) | アプリを起動し、そのターミナルタブを開きます。アプリが停止中のときに表示されます。 |
| 停止 (四角) | アプリを停止します。実行中または起動中に表示されます。 |

![実行中の行を拡大: ステータスの点、種類のアイコン、名前とポート、続いて編集、再起動、停止のボタン](../../../../assets/screenshots/sidebar-row-controls.png)

1. ステータスの点 (実行中は点灯)。
2. 種類のアイコン。
3. 編集 (鉛筆)。
4. 再起動。
5. 停止 (実行中は起動の代わりに表示)。

起動や停止の処理中は、操作ボタンの代わりにスピナーが表示されます (`処理中...`)。

アプリの **名前** をクリックすると、そのターミナルタブを開くか、フォーカスするだけで、何も起動しません。停止中のアプリのタブには、このセッションのログが表示されます。起動するには、起動または再起動を使います。`url` だけで `command` のない `static` アプリにはターミナルがなく、起動するとブラウザーで URL が開きます。

### ツールチップ

名前にカーソルを合わせると、アプリに `note` があればそれが、なければ名前が表示されます。`note` は、エディターか `apps.json` で設定します。

### MCP の子項目

AI クライアントがアプリ自身の MCP ツールを使うと、アプリの下に薄く表示された子項目 `MCP サーバー` が現れます。クライアントが接続している間は、その点が点灯し、ツールチップに「MCP クライアント接続中」と表示されます。停止ボタンで、そのプロセスを終了できます。

この行は、`processName` と `mcp` 引数でプロセスを見つけます。アプリに `mcpProcessName` のパターンが設定されている場合は、それを使います。[フィールド](/ja/apps/fields/#mcpprocessname)を参照してください。

これらの行は、設定の **MCP プロセスを表示** で非表示にできます。[MCP のセットアップ](/ja/automation/mcp-setup/#独自の-mcp-サーバーを持つアプリ)を参照してください。

## グループ

![5 つのグループ見出しを枠線で強調したアイドル状態のサイドバー。右側に各グループのアプリ数が表示されている](../../../../assets/screenshots/sidebar-groups-narrow.png)

- グループの見出しをクリックすると、折りたたみ、展開ができます。横の数は、表示されているアプリの数です。折りたたんだ状態は記憶されます。
- グループ内では、最後に起動したアプリが一番上に来ます。一度も起動していないアプリは、`apps.json` の順序のままです。起動したばかりのアプリは光って、一番上に上がります。

## 絞り込みボックス

**アプリを絞り込む...** に入力すると、一覧が絞り込まれます。アプリ名とグループ名に、大文字小文字を区別せずに一致します。何も一致しない場合は、一覧に次のように表示されます。

```text
No apps match "<text>".
```

日本語の画面では、`「{filter}」に一致するアプリはありません。` のように、テキストがかぎ括弧で囲まれて表示されます。下の削除の確認も同様です。

## 右クリックメニュー

行を右クリックすると、次の項目が表示されます。

| 項目 | 動作 |
| --- | --- |
| 編集 | アプリエディターを開きます。 |
| 名前を変更 | 名前を編集欄に変えます。**Enter** かほかの場所のクリックで保存し、**Esc** でキャンセルします。空の名前や変更のない名前は無視されます。 |
| アイコンを設定... | アイコンとして使う画像ファイル (png、jpg、jpeg、gif、svg、webp、ico) を選びます。 |
| 削除 | `「{name}」を削除しますか?` と確認し、`apps.json` からエントリーを削除します。Moonpool がそのアプリを実行している場合は、先に停止します。 |

**Esc** を押すと、何もせずにメニューが閉じます。

## サイズ変更

サイドバーと CLI パネルの間の境界線をドラッグします。幅は 180 から 620 px (既定は 280) に制限され、記憶されます。CLI パネルが折りたたまれている間、境界線はロックされます。[ターミナルタブ](/ja/using/terminal-tabs/)を参照してください。
