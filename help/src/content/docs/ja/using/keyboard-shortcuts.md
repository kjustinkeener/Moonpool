## キーボード

| キー | 場所 | 動作 |
| --- | --- | --- |
| F5、Ctrl+R、Cmd+R | ハブ | メニューの **再読み込み** と同じく、`apps.json` をディスクから再び読み込みます。ページ自体は更新されません。 |
| Esc | コンテキストメニュー | 閉じます。 |
| Esc | アプリの名前変更中 | 名前の変更をキャンセルします。 |
| Esc | 設定、情報、アプリエディターのウィンドウ | ウィンドウを閉じます (エディターは、変更を破棄する前に確認します)。 |
| Enter | アプリの名前変更中 | 新しい名前を保存します。 |

## マウス

| 操作 | 場所 | 動作 |
| --- | --- | --- |
| Ctrl + ホイール | ハブ | UI を拡大、縮小します。 |
| テキストを選択 | ターミナル | 選択範囲をコピーし、選択を解除します。 |
| 中クリック | ターミナル | 貼り付けます。 |
| 右クリック | サイドバーの行 | 行のメニューを開きます。[サイドバーとメニュー](/ja/using/sidebar-and-menus/)を参照してください。 |

## ズーム

Ctrl を押しながら、ハブ上でホイールをスクロールするとズームします。上にスクロールすると拡大、下にスクロールすると縮小で、ホイール 1 回あたり約 10 パーセントずつ変化します。

```text
Ctrl + wheel up      zoom in
Ctrl + wheel down    zoom out
```

- 範囲は 0.5 倍から 3 倍です。
- ウィンドウも同じ倍率でサイズが変わるので、2 倍でも 1 倍と同じ密度のレイアウトが保たれます。上限に達すると、ウィンドウはそれ以上大きくなりません。
- 倍率は `settings.json` の `uiScale` として保存され、次回の起動時に適用されます。保存されるウィンドウサイズはすでにズーム後のサイズなので、再び倍率がかかることはありません。[settings.json](/ja/data/settings-json/)を参照してください。

- ズームが適用されるのはハブウィンドウだけです。設定、情報、アプリエディター、ヘルプは、それぞれのサイズのままです。

`uiScale` を変更する設定項目はなく、リセット用のキーもありません。元のサイズに戻すには、同じ回数だけ逆方向にスクロールするか、Moonpool を終了して `settings.json` の `uiScale` を `1` にし (またはキーを削除し)、再び起動してください。
