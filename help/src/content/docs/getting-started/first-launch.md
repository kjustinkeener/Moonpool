title: First Launch
description: What you see the first time Moonpool starts, and how to reach it later.
---

The first time Moonpool runs it seeds a few example apps so the hub is not empty, and
places its icon in the system tray.

## Finding the hub

- Click the **tray icon** to raise the hub window.
- Closing the window hides it back to the tray; Moonpool keeps running.
- Right-click the tray icon for quick actions.

## Getting help

The **Help** entry opens this help site in its own window, and works offline. It is the
same content published on the web, so you can read it with or without a connection.
