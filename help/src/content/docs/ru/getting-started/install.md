Эта страница о Windows. В Windows Moonpool сам является установщиком: загружается один файл
`moonpool.exe`. В Linux нет карточки установки и выбора портативного режима; см.
[Linux](/ru/platforms/linux/).

## Установленный режим

Запустите загруженный `moonpool.exe`. При первом запуске он показывает карточку установки. В
ней три элемента управления: кнопка **Установить Moonpool**, флажок **ярлык на рабочем столе**
(включён по умолчанию) и ссылка **Портативная установка**.

Установка копирует Moonpool в ваш профиль пользователя, в папку `.moonpool\`, добавляет ярлык в
меню «Пуск» (и на рабочий стол, если флажок установлен) и регистрирует запись в разделе
«Установка и удаление программ». Затем она запускает установленную копию и закрывается. Загруженный
вами файл остаётся там, где был; его можно удалить. После этого запускайте Moonpool по ярлыку, как
любое другое приложение.

![Карточка установки: кнопка «Install Moonpool», флажок ярлыка на рабочем столе, ссылка «Install portable» и путь установки](../../../../assets/screenshots/installer-window.png)

Всё, что нужно Moonpool, находится в этой одной папке: программа, ваша конфигурация и
встроенная справка.

```text title="Installed layout"
%USERPROFILE%\.moonpool\
```

## Установить Moonpool... из меню

В Windows в меню «...» есть пункт **Установить Moonpool...** в обоих режимах. Он открывает ту же
карточку установки. Из портативной копии её можно установить как обычную программу. В установленной
копии кнопка **Установить Moonpool** недоступна («Уже установлено»), а **Портативная установка**
остаётся доступной.

## Удаление

Воспользуйтесь разделом Windows «Установка и удаление программ» («Установленные приложения») или
запустите установленную копию с параметром `--uninstall`. Её нет в PATH, поэтому укажите полный
путь:

```powershell frame="terminal"
& "$env:USERPROFILE\.moonpool\moonpool.exe" --uninstall
```

Это удаляет ярлыки из меню «Пуск» и с рабочего стола, запись в реестре и всю папку
`%USERPROFILE%\.moonpool`, **включая вашу конфигурацию** (`apps.json`, настройки и журналы).
Если хотите сохранить конфигурацию, сначала сделайте резервную копию этой папки:

```text
%USERPROFILE%\.moonpool\moonpool-config
```

Любой запущенный Moonpool останавливается в ходе удаления.

## Портативный режим

Предпочитаете USB-накопитель или переносимую папку? Нажмите **Портативная установка** в карточке
установки и выберите папку. См. [Портативный режим](/ru/data/portable-mode/).
