Moonpool обновляет себя сам. Скачивать отдельный установщик и проходить мастер
не нужно.

## Как приходят обновления

Moonpool получает `update.json` (`linux-update.json` в Linux) из GitHub Releases проекта,
сравнивает версии и предлагает только строго более новую. Он проверяет:

- при запуске, если параметр **Проверять обновления при запуске** не выключен в
  [Настройках](/ru/using/settings/);
- всякий раз, когда вы нажимаете **Проверить обновления** в окне «О программе». Эта кнопка устанавливает более новую
  версию сразу и перезапускает Moonpool. Иначе она сообщает, что у вас последняя
  версия, или показывает ошибку.

Окно «О программе» показывает запущенную вами версию под названием:

![Верх окна «О программе»: логотип, название (1) и строка версии под ним](../../../../assets/screenshots/about-header.png)

1. Название. Строка под ним - это версия и дата сборки.

Каждая загрузка проверяется по ключу подписи minisign Moonpool, прежде чем будет применена, поэтому
подделанная или повреждённая загрузка отклоняется. Moonpool никогда не устанавливает более старую версию.

## Баннер обновления

При запуске найденное обновление показывается баннером на пустом экране хаба:

```text
Доступна версия Moonpool {version} (у вас {current}).
```

Баннер показывается только пока не открыта ни одна вкладка приложения и панель CLI развёрнута. Когда панель
свёрнута, вместо этого пульсирует стрелка рядом с полем фильтра. При открытой вкладке никакого
признака нет вообще. Чтобы увидеть баннер, закройте все вкладки (и разверните панель) или воспользуйтесь **Проверить
обновления** в окне «О программе».

Нажмите **Скачать и установить**, и Moonpool заменит себя и перезапустится, либо скройте
баннер крестиком.

## Портативные копии

Портативная копия обновляет `moonpool.exe` в собственной папке `.moonpool\` тем же способом.
Каждая копия проверяет и обновляется независимо. Папка должна быть доступна для записи, поэтому копия на
накопителе или общем ресурсе только для чтения не может обновить себя; скопируйте поверх неё более новый `moonpool.exe` вручную.

## Linux

Сам обновляется только AppImage. Он заменяет файл AppImage на месте, поэтому храните его в
папке, в которую можно писать. Установка `.deb` или RPM обновляется вашим менеджером пакетов:
установка из Moonpool завершается ошибкой

```text
automatic updates are available for the AppImage only; update the .deb or RPM with your package manager
```

См. [Linux](/ru/platforms/linux/#обновления).

## Когда обновление не удалось

Баннер показывает причину, а кнопка снова становится доступной, чтобы можно было повторить:

```text
Не удалось обновить: <error>
```

| Ошибка содержит | Вероятная причина | Что делать |
| --- | --- | --- |
| `download failed` | Нет соединения, прокси или GitHub ограничивает запросы | Подождите и повторите либо обновите вручную. |
| `signature verification FAILED - refusing to install` | Загрузка повреждена или изменена | Повторите. Если сбой повторяется, обновите вручную со страницы Releases. |
| `rename self aside` или `write new exe` | Папка только для чтения или антивирус удерживает файл | Сделайте папку доступной для записи или разрешите `moonpool.exe` в антивирусе, затем повторите. |
| `refusing to install ... not newer than current` | Предложенная версия не новее | Ничего делать не нужно. |

### Обновление вручную

Закройте Moonpool, скачайте `moonpool.exe` со
[страницы Releases](https://github.com/kjustinkeener/Moonpool/releases) проекта и скопируйте его поверх
старого: `%USERPROFILE%\.moonpool\moonpool.exe` для установленной версии или файла в вашей папке `.moonpool\`
для портативной копии. Ваша папка конфигурации не затрагивается. В Linux замените
AppImage или воспользуйтесь менеджером пакетов.

## Справка тоже обновляется

Эта справка поставляется внутри Moonpool, поэтому каждое обновление программы приносит с собой соответствующую справку.
Автономная копия всегда соответствует запущенной вами версии.
