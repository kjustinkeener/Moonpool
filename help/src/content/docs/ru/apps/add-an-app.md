Каждое приложение в Moonpool - это одна запись с командой запуска, рабочей папкой и необязательным
окружением. Moonpool выполняет команду в собственном управляемом терминале.

## Добавление приложения

1. Откройте меню **...** вверху боковой панели и выберите **Добавить приложение**.
2. Введите **name** и выберите **group**.
3. Выберите **type**: `web` (сервер на порту), `desktop` (обычное приложение), `static` (страница) или `cli` (команда).
4. Задайте **command** и **cwd**, в котором она выполняется.
5. Заполните то, что нужно для типа: **port** и **url** для web, **processName** для desktop,
   **url** для static. Для приложения `static`, у которого есть только `url`, **command** и **cwd** не нужны.
6. Сохраните. Приложение появится на боковой панели. Чтобы запустить его, используйте элемент **Запустить**.

![Выбор типа (1) и поле port (2) в редакторе приложения, между ними cwd и command](../../../../assets/screenshots/edit-app-type-and-port.png)

1. Список **type**; его подсказка объясняет, как запускается этот тип.
2. Поле **port**, которое используют приложения `web`.

В результате получается одна запись в `apps.json`, например:

```json title="apps.json"
{
  "id": "my-api",
  "name": "My API",
  "group": "Dev",
  "type": "web",
  "command": "npm run dev",
  "cwd": "C:\\code\\my-api",
  "port": 3000,
  "url": "http://localhost:3000"
}
```

Щелчок по названию приложения только открывает его вкладку терминала; см. [Состояния приложения](/ru/support/glossary/#состояния-приложения).

## Редактор приложения

- **Группа.** Выберите группу из списка или выберите **+ Новая группа...** и введите название.
  **назад к списку** возвращает к списку. Пустая группа сохраняется как `Apps`.
- **Затемнённые поля** выбранный тип не использует. Они всё равно сохраняются.
- **Сохранение без названия** показывает `укажите название.`
- **Esc** или закрытие редактора с несохранёнными изменениями вызывает вопрос «Отменить внесённые изменения?».
- Чтобы изменить приложение позже, нажмите на карандаш в его строке или щёлкните по нему правой кнопкой и выберите **Изменить**.

## Правка вручную

Выберите **Изменить apps.json** в том же меню, сохраните файл, затем выберите **Обновить**. Формат,
правила проверки и варианты восстановления описаны в
[обзоре конфигурации](/ru/apps/apps-json/).
