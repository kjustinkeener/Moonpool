Каждое приложение работает в собственной вкладке терминала на панели CLI.

## Вкладки

![Полоса вкладок с активной вкладкой Metrics Dashboard (выделена) и её живым журналом ниже; у каждой вкладки есть индикатор и крестик](../../../../assets/screenshots/hub-terminal-tab.png)

- Запуск приложения или щелчок по его названию на боковой панели открывает его вкладку. Щелчок по названию ничего не запускает; см. [Состояния приложения](/ru/support/glossary/#состояния-приложения).
- Индикатор на вкладке светится, пока приложение работает.
- Крестик **x** на вкладке закрывает вкладку. Он не останавливает приложение. Щёлкните название ещё раз, чтобы снова открыть вкладку; она покажет журнал этого сеанса.

## Сворачивание панели

Крестик **x** в дальнем правом углу полосы вкладок («Скрыть панель CLI») сворачивает панель CLI и
уменьшает окно до одной боковой панели. Терминалы продолжают работать и сохраняют свою историю
прокрутки.

Рядом с полем фильтра появляется стрелка, возвращающая панель с прежней шириной. Стрелка пульсирует,
когда ожидается обновление, потому что баннер обновления находится в этой панели.

## Копирование и вставка

| Действие | Результат |
| --- | --- |
| Выделение текста мышью | Копируется в буфер обмена при отпускании кнопки, затем выделение снимается. |
| Щелчок средней кнопкой | Вставляет содержимое буфера обмена в терминал. |
| Кнопка **Копировать всё** (вверху справа, появляется при наведении) | Копирует всю историю прокрутки как текст. |

## История прокрутки

Каждый терминал хранит 10 000 строк.

## Когда процесс завершается

Когда процесс завершается, терминал выводит:

```text
[process exited]
```

Вкладка остаётся открытой, а её вывод сохраняется. Строка `[process exited]` отображается на
вашем языке (в русском интерфейсе это `[процесс завершён]`).

## Перезапуск

**Перезапустить** (или «Запустить» для остановленного приложения) начинает новый запуск в той же
вкладке. Вкладка пересоздаётся, а прежний вывод этого сеанса воспроизводится в неё из журнала
сеанса.

Если приложение уже запускалось ранее в этом сеансе, Moonpool сначала записывает в журнал сеанса
тусклый разделитель, чтобы он отображался между прежним выводом и новым запуском:

```text
---------- restarted 2026-10-05 09:14:02 ----------
```

Если новый запуск начинается с очистки экрана, прежний вывод вытесняется в историю прокрутки, а не
стирается.

## Журналы сеансов

Всё, что выводит приложение, также записывается в файл журнала в `cli-output\`, по одному файлу на
приложение на сеанс Moonpool. Расположение, хранение и параметр **Сохранять журналы вывода приложений между сеансами** описаны в разделе [Журналы](/ru/data/logs/).
