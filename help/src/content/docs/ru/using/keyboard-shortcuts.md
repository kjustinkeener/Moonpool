## Клавиатура

| Клавиши | Где | Действие |
| --- | --- | --- |
| F5, Ctrl+R, Cmd+R | Главное окно | Заново читает `apps.json` с диска, как пункт **Обновить** в меню. Сама страница не перезагружается. |
| Esc | Контекстное меню | Закрывает его. |
| Esc | Переименование приложения | Отменяет переименование. |
| Esc | Окна настроек, «О программе» и редактора приложений | Закрывает окно (редактор спрашивает перед отменой изменений). |
| Enter | Переименование приложения | Сохраняет новое название. |

## Мышь

| Действие | Где | Результат |
| --- | --- | --- |
| Ctrl + колесо | Главное окно | Изменяет масштаб интерфейса. |
| Выделение текста | Терминал | Копирует и снимает выделение. |
| Щелчок средней кнопкой | Терминал | Вставляет. |
| Щелчок правой кнопкой | Строка боковой панели | Открывает меню строки. См. [Боковая панель и меню](/ru/using/sidebar-and-menus/). |

## Масштаб

Удерживайте Ctrl и прокручивайте колесо над главным окном, чтобы изменить масштаб. Прокрутка вверх
увеличивает, вниз уменьшает, примерно на 10 процентов за одно событие колеса.

```text
Ctrl + wheel up      zoom in
Ctrl + wheel down    zoom out
```

- Диапазон составляет от 0,5x до 3x.
- Размер окна изменяется в той же пропорции, поэтому компоновка при 2x остаётся такой же плотной,
  как при 1x. По достижении предела окно перестаёт расти.
- Коэффициент сохраняется как `uiScale` в `settings.json` и применяется при следующем запуске.
  Сохранённый размер окна уже учитывает масштаб, поэтому повторно не масштабируется. См.
  [settings.json](/ru/data/settings-json/).

- Масштаб применяется только к главному окну. Настройки, «О программе», редактор приложений и
  справка сохраняют свой размер.

Для `uiScale` нет элемента управления в настройках и нет клавиши сброса. Чтобы вернуться к обычному
размеру, прокрутите колесо обратно на то же число щелчков либо завершите Moonpool, задайте
`uiScale` равным `1` в `settings.json` (или удалите ключ) и запустите его снова.
