Откройте **Настройки** из меню «...» главного окна. Изменения сохраняются сразу. Esc закрывает
окно. На этой странице приведён полный список настроек. Каждая из них сохраняется в `settings.json`
под указанным ключом; сам файл описан в разделе [settings.json](/ru/data/settings-json/).

![Окно настроек: переключатели и ползунки в левом столбце, параметры журналов в правом](../../../../assets/screenshots/settings-window.png)

## Сброс элемента управления

Щёлкните правой кнопкой любой флажок, ползунок или числовое поле, чтобы сбросить только эту
настройку к значению по умолчанию. Об этом говорит всплывающая подсказка у каждого элемента.
У выбора языка и темы сброса нет.

## Левый столбец

| Элемент | Ключ | По умолчанию | Что делает |
| --- | --- | --- | --- |
| Язык | `locale` | Авто (как в системе) | Язык собственного текста Moonpool. Применяется мгновенно. См. [Темы, язык и прозрачность](/ru/using/themes-and-language/). |
| Тема | нет (хранилище браузера) | Авто (как в системе) | Цветовая тема. Кнопка открывает обозреватель тем с предпросмотром каждой темы; щелчок по теме применяет её мгновенно. См. [Темы, язык и прозрачность](/ru/using/themes-and-language/). |
| Закрывать в трей | `closeToTray` | выкл. | Вкл.: закрытие окна скрывает Moonpool в трей. Выкл.: закрытие завершает работу. |
| Сворачивать в трей | `minimizeToTray` | вкл. | Вкл.: сворачивание скрывает Moonpool в трей, и он исчезает с панели задач. Выкл.: сворачивает на панель задач. |
| Поверх всех окон | `alwaysOnTop` | выкл. | Держит все окна Moonpool поверх других окон. |
| Показывать в трее | `showInTray` | вкл. | Оставляет значок в трее видимым. |
| Показывать на панели задач | `showInTaskbar` | вкл. | Оставляет кнопку на панели задач видимой. |
| Показывать строку состояния CPU и памяти | `showStatusbar` | вкл. | Живая полоса загрузки CPU и памяти внизу главного окна. |
| Показывать процессы MCP | `showMcpProcesses` | вкл. | Показывает MCP-процесс приложения как подстроку MCP на боковой панели, пока используются его MCP-инструменты. |
| Прозрачность фона | `transparency` | 0 % | Ползунок от 0 до 90 с шагом 5. См. [Темы, язык и прозрачность](/ru/using/themes-and-language/#прозрачность). |
| Проверять обновления при запуске | `checkOnStartup` | вкл. | Проверяет на GitHub наличие более новой версии при запуске и показывает баннер, если она найдена. См. [Обновление](/ru/data/updating/). |

### Блокировка трея и панели задач

Хотя бы один из параметров **Показывать в трее** и **Показывать на панели задач** должен оставаться
включённым, иначе у скрытого окна не будет пути назад. Когда включён только один из них, его
флажок недоступен, пока вы не включите другой обратно.

## Правый столбец: журналы

| Элемент | Ключ | По умолчанию | Что делает |
| --- | --- | --- | --- |
| Сохранять журналы вывода приложений между сеансами | `cliLogging` | выкл. | Вывод терминала текущего сеанса всегда сохраняется для его собственных вкладок. Вкл.: журналы прошлых сеансов остаются на диске в `cli-output\` в пределах лимита хранения. Выкл.: они удаляются при следующем запуске этого приложения. |
| Хранение журналов на приложение | `logRetentionMb` | 10 МБ | Лимит на общий размер журналов каждого приложения. Минимум 1. Недоступен, пока переключатель выше выключен. Журнал текущего сеанса учитывается в лимите, но никогда не обрезается и не удаляется из-за него. |
| Записывать отладочные данные в файл | `debugLogging` | выкл. | Записывает загрузки `apps.json`, запуски и ошибки в `moonpool.log`. |

Под каждой группой журналов поле с путём показывает расположение и две кнопки:

- **Открыть** открывает папку в файловом менеджере (**Открыть папку журналов CLI** для `cli-output\`, **Открыть журнал** для `moonpool.log`).
- **Копировать** помещает путь в буфер обмена (**Копировать путь к папке журналов CLI**, **Копировать путь к файлу журнала**).

Форматы файлов журналов, разделитель перезапуска и правила хранения описаны в разделе
[Журналы](/ru/data/logs/).

Если флажок не удаётся сохранить, красное сообщение в верхней части окна сообщает об этом, а
флажок возвращается в прежнее положение.

## Окно «О программе»

Откройте **О программе** из меню «...».

![Окно «О программе» со строкой версии, ссылками и кнопками «Проверить обновления» и «Закрыть»](../../../../assets/screenshots/about-window.png)

Оно показывает:

- Версию и дату сборки.
- Ссылки на сайт проекта, репозиторий GitHub и контактный адрес.
- **Проверить обновления**. Если существует более новая версия, она скачивается, проверяется и
  устанавливается, после чего Moonpool перезапускается. В противном случае сообщается, что у вас
  последняя версия, либо ошибка, если проверка не удалась.
- Благодарности библиотекам, с помощью которых создан Moonpool, и автору.

Esc закрывает окно. Окно «О программе» сразу следует настройкам темы, прозрачности и языка.
