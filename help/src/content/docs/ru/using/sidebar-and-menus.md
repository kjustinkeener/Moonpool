Боковая панель перечисляет все приложения из `apps.json`, сгруппированные по полю `group` каждого приложения. См. [Поля приложения](/ru/apps/fields/).

## Строки

Каждая строка показывает индикатор состояния, значок приложения (или глиф типа, если значка нет), название, порт, если он задан (`:3000`), и кнопки управления.

| Индикатор | Значение |
| --- | --- |
| Сплошной | работает |
| Пульсирующий | запуск: Moonpool запустил приложение, но оно ещё не обнаружено как работающее |
| Серый | остановлено |

Наведите указатель на индикатор, чтобы увидеть слово.

![Боковая панель с двумя выделенными работающими веб-приложениями: светящиеся индикаторы и кнопки «Остановить»](../../../../assets/screenshots/sidebar-running-narrow.png)

1. Два работающих приложения. Их индикаторы светятся, а кнопка «Остановить» (квадрат) заменяет «Запустить».

| Элемент | Действие |
| --- | --- |
| Карандаш | Изменить приложение. |
| Перезапустить | Остановить и запустить заново. Для остановленного приложения просто запускает его. |
| Запустить (воспроизведение) | Запускает приложение и открывает вкладку его терминала. Отображается, когда приложение остановлено. |
| Остановить (квадрат) | Останавливает приложение. Отображается, пока оно работает или запускается. |

![Одна работающая строка крупно: индикатор состояния, значок типа, название и порт, затем кнопки изменения, перезапуска и остановки](../../../../assets/screenshots/sidebar-row-controls.png)

1. Индикатор состояния (светится, пока приложение работает).
2. Значок типа.
3. Изменить (карандаш).
4. Перезапустить.
5. Остановить (показывается вместо «Запустить», пока приложение работает).

Пока выполняется запуск или остановка, кнопки заменяются индикатором загрузки (`Выполняется...`).

Щелчок по **названию** приложения открывает или выделяет вкладку его терминала и никогда ничего не запускает. Вкладка остановленного приложения показывает журнал этого сеанса. Чтобы запустить приложение, используйте «Запустить» или «Перезапустить». У приложения `static`, у которого есть только `url` и нет `command`, терминала нет: «Запустить» открывает URL в браузере.

### Подсказка

При наведении на название показывается `note` приложения, если он есть, иначе его название. Задайте `note` в редакторе или в `apps.json`.

### Подстрока MCP

Когда ИИ-клиент использовал собственные MCP-инструменты приложения, под приложением появляется
приглушённая подстрока `MCP-сервер`. Её индикатор светится, а подсказка гласит «MCP-клиент
подключён», пока клиент подключён. Кнопка остановки завершает этот процесс.

Строка находит процесс по `processName` плюс аргумент `mcp` либо по шаблону `mcpProcessName`
приложения, если он задан. См. [поля](/ru/apps/fields/#mcpprocessname).

Скройте эти строки параметром **Показывать процессы MCP** в настройках. См.
[Настройка MCP](/ru/automation/mcp-setup/#приложения-с-собственным-mcp-сервером).

## Группы

![Боковая панель в покое с выделенными заголовками пяти групп, у каждой справа число приложений](../../../../assets/screenshots/sidebar-groups-narrow.png)

- Щёлкните заголовок группы, чтобы свернуть или развернуть её. Число рядом - количество показанных приложений. Свёрнутые группы запоминаются.
- Внутри группы наверху находится приложение, запущенное последним. Приложения, которые ни разу не запускались, сохраняют порядок из `apps.json`. Только что запущенное приложение светится и поднимается наверх.

## Поле фильтра

Вводите текст в **Фильтр приложений...**, чтобы сузить список. Сравнение идёт по названию приложения и названию группы без учёта регистра. Если ничего не найдено, список показывает:

```text
Нет приложений по запросу «<text>».
```

Приложение показывает типографские кавычки вокруг текста, здесь и в запросе на удаление ниже.

## Меню по правому щелчку

Щёлкните строку правой кнопкой, чтобы открыть:

| Пункт | Действие |
| --- | --- |
| Изменить | Открывает редактор приложений. |
| Переименовать | Превращает название в поле редактирования. **Enter** или щелчок в сторону сохраняет, **Esc** отменяет. Пустое или неизменённое название игнорируется. |
| Выбрать значок... | Выберите файл изображения (png, jpg, jpeg, gif, svg, webp, ico), который станет значком. |
| Удалить | Спрашивает `Удалить «<name>»?` и удаляет запись из `apps.json`. Если Moonpool запустил это приложение, оно сначала останавливается. |

**Esc** закрывает меню без действий.

## Изменение ширины

Перетащите разделитель между боковой панелью и панелью CLI. Ширина ограничена диапазоном от 180 до 620 px (по умолчанию 280) и запоминается. Пока панель CLI свёрнута, разделитель заблокирован. См. [Вкладки терминала](/ru/using/terminal-tabs/).
