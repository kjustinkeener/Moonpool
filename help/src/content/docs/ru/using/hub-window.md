## Расположение элементов

| Область | Что в ней |
| --- | --- |
| Строка заголовка | Свернуть, развернуть и закрыть. |
| Боковая панель | Поле фильтра, меню **...** и ваши приложения, сгруппированные по `group`. См. [Боковая панель и меню](/ru/using/sidebar-and-menus/). |
| Панель CLI | По одной вкладке терминала на каждое открытое приложение. См. [Вкладки терминала](/ru/using/terminal-tabs/). |
| Строка состояния | Загрузка CPU и памяти в реальном времени, вдоль нижнего края. |

Перетащите разделитель между боковой панелью и панелью CLI, чтобы изменить ширину боковой панели.

## Строка состояния

![Строка состояния: полосы загрузки по ядрам CPU слева, полоса памяти справа](../../../../assets/screenshots/status-bar.png)

Строка состояния показывает по одной тонкой полосе на каждое ядро CPU (наведите указатель, чтобы
увидеть «Загрузка CPU по ядрам»), а затем полосу памяти (ОЗУ) с подписью `used/total GB`.
Отключите её параметром **Показывать строку состояния CPU и памяти** в настройках
(`showStatusbar`; см. [Окно настроек](/ru/using/settings/)). Изменение применяется сразу.

## Меню ...

Кнопка **...** слева от поля фильтра открывает меню.

![Кнопка меню ... (1) и поле «Фильтр приложений» (2) в верхней части боковой панели](../../../../assets/screenshots/sidebar-filter-and-menu.png)

1. Кнопка меню **...**.
2. Поле **Фильтр приложений...**.

| Пункт | Действие |
| --- | --- |
| Добавить приложение | Открывает редактор приложений. См. [Добавление приложений](/ru/apps/add-an-app/). |
| Изменить apps.json | Открывает `apps.json` в редакторе по умолчанию для правки вручную. |
| Обновить | Заново читает `apps.json` с диска (также F5, см. [Сочетания клавиш и масштаб](/ru/using/keyboard-shortcuts/)). |
| Настройки | Открывает окно настроек. |
| Справка | Открывает эту справку. |
| О программе | Открывает окно «О программе» с версией и проверкой обновлений. |
| Установить Moonpool... | Только Windows. Открывает окно установщика, чтобы установить приложение или создать портативную копию. См. [Установка](/ru/getting-started/install/) и [Портативный режим](/ru/data/portable-mode/). |

### Предупреждение о конфликте портов

Если два приложения в `apps.json` используют один и тот же `port`, в нижней части меню появляется
строка с предупреждением, например:

```text
port 3000: App A / App B
```

Наведите на неё указатель, чтобы увидеть полную фразу. Устраните конфликт в `apps.json` или в
редакторе приложений; строка исчезнет, когда общих портов не останется.

## Когда в apps.json ошибка

Если при обновлении (или нажатии F5) выясняется, что `apps.json` больше не разбирается или не
проходит проверку, Moonpool сохраняет уже имевшийся список. Баннер в верхней части боковой панели
сообщает «В apps.json ошибка, показан последний загруженный список», за которым следует сама ошибка
(наведите указатель, чтобы увидеть полный текст). Список ниже затемнён, но работает, поэтому вы
по-прежнему можете запускать и останавливать приложения. Кнопка **Изменить apps.json** в баннере
открывает файл; исправьте его и выберите **Обновить**, и баннер исчезнет.

Пока файл не загрузится снова, Moonpool не будет сохранять изменения из редактора приложений,
переименования, удаления или выбора значка, поэтому повреждённый файл никогда не будет
перезаписан.

Если файл уже повреждён при запуске Moonpool, сохранять нечего: баннер сообщает, что приложения не
загружены, а боковая панель пуста. Исправьте файл и обновите либо вернитесь к недавней исправной
копии (см. [Если файл повреждён](/ru/apps/apps-json/#если-файл-повреждён)).

## Пустой экран

Если ни одна вкладка не открыта, панель CLI показывает «Выберите приложение слева, чтобы запустить
его.» В ней также есть два элемента, которые появляются только при отсутствии открытых вкладок:

- **Баннер обновления**, если при запуске найдена более новая версия. См.
  [Обновление](/ru/data/updating/).
- **Скопировать запрос** - готовый запрос, который поручает настройку ваших приложений ИИ-агенту.
  См. [ИИ-агенты: быстрый старт](/ru/automation/quick-start/#скопировать-запрос).

Значок в трее, закрытие, сворачивание, выход и режим «поверх всех окон» описаны в разделе
[Трей, закрытие и сворачивание](/ru/using/tray-and-closing/).

## Размер, положение и развёрнутое состояние

Moonpool запоминает размер, положение и развёрнутое состояние главного окна между запусками. При
первом запуске окно открывается размером 1200x780 в положении, которое выбирает Windows.

Если сохранённое положение больше не попадает ни на один подключённый дисплей (например, монитор
отключён), положение игнорируется, а сохранённый размер используется в положении по умолчанию.
Файл называется `window-state.json` и находится в папке конфигурации (см.
[Где хранится конфигурация](/ru/apps/apps-json/#где-находится-конфигурация)).

Ширина боковой панели и то, свёрнута ли панель CLI, тоже запоминаются.
