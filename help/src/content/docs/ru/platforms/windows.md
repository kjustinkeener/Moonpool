Windows - основная платформа Moonpool. Установите его так, как описано в разделе
[Установка](/ru/getting-started/install/).

## Перед запуском

- **SmartScreen.** `moonpool.exe` не имеет цифровой подписи, поэтому при первом запуске Windows
  может показать окно «Windows protected your PC» («Windows защитила ваш компьютер»). Выберите
  **More info** («Подробнее»), затем **Run anyway** («Выполнить в любом случае»).
- **Антивирус.** Новый неподписанный exe-файл, который копирует сам себя и заменяет себя при
  обновлении, может сработать на антивирус. Если ваш антивирус блокирует `moonpool.exe` или
  помещает его в карантин, разрешите его для папки `.moonpool`.
- **WebView2.** Окна Moonpool используют Microsoft Edge WebView2, который входит в состав Windows 11
  и актуальной Windows 10. Если окно остаётся пустым или не открывается, установите Evergreen
  WebView2 Runtime от Microsoft.

Подробнее: [Windows защитила ваш компьютер](/ru/support/windows-protected-your-pc/),
[Отсутствует среда WebView2](/ru/support/webview2-runtime-missing/) и
[Автоматический запуск скрипта или сервера разработки при входе в Windows](/ru/guides/start-app-at-windows-login/).

## Трей

В Windows 11 новый значок в трее часто попадает в область скрытых значков. Нажмите стрелку **^**
в правой части панели задач, чтобы найти его, и перетащите его на панель задач, чтобы он
оставался видимым.

## Команды

- Команды выполняются через `cmd /c`. Избегайте вложенных двойных кавычек в `command`; `cmd /c`
  их искажает. Для скрипта, после которого должна оставаться открытой оболочка, используйте
  `pwsh -NoLogo -NoProfile -NoExit -Command <script and args>` без кавычек вокруг части со
  скриптом.
- `processName` сопоставляется с `.exe` или без него, без учёта регистра.
- Остановка завершает всё дерево процессов, запущенных Moonpool, включая процессы, которые от
  него отсоединились.
- Приложениям Docker Desktop нужен `killMode` со значением `none` или `command`, но не `port`. См.
  [Приложения Docker в Windows](/ru/apps/stop-and-restart/#приложения-docker-в-windows).

## Чем отличаются платформы

| | Windows | Linux |
| --- | --- | --- |
| Установка | Самоустанавливающийся `moonpool.exe` или портативный режим | AppImage, `.deb` или RPM; карточки установки нет |
| Самообновление | Да, для установленной и портативной копии | Только AppImage |
| Папка конфигурации | `%USERPROFILE%\.moonpool\moonpool-config\` | `~/.config/Moonpool/` |
| Оболочка для команд | `cmd /c` | `$SHELL -c` |
| `processName` | Любая длина, `.exe` необязательно, без учёта регистра | Не более 15 символов, с учётом регистра |
| Остановка по `processName` | Завершает процесс и его дочерние процессы | Завершает только процессы с точно таким именем |
| Канал управления | Именованный канал | Сокет Unix |
| Снимки окон (для тестирования) | Да | Нет |
| Значки из программного файла | Да | Нет |
| Трей | Работает сразу | Нужен AppIndicator; в стандартном GNOME нужно расширение |

Подробности о Linux приведены на странице [Linux](/ru/platforms/linux/).
