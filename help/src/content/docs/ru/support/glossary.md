## Приложения

| Термин | Значение |
| --- | --- |
| приложение | Всё, чем управляет Moonpool: сервер разработки, настольное приложение, страница или команда. |
| запись | Запись приложения в `apps.json`. Используется только при разговоре о JSON. |
| строка приложения | Строка приложения на боковой панели с индикатором состояния и кнопками управления. |
| группа | Заголовок на боковой панели, под которым перечислено приложение, из его поля `group`. |
| тип | `web`, `desktop`, `static` или `cli`. Определяет, какие поля имеют значение. См. [Типы приложений](/ru/apps/types/). |
| id | Постоянный ключ приложения, используемый в именах файлов, командах и инструментах агентов. См. [Идентификатор id](/ru/apps/apps-json/#идентификатор-id). |

## Состояния приложения

| Состояние | Значение |
| --- | --- |
| запуск | Moonpool запустил приложение, но ещё не увидел, что оно работает. Пульсирующий индикатор. |
| работает | Его `port` отвечает, его `processName` существует или, если не задано ни то ни другое, запущенный Moonpool терминал ещё жив. Сплошной индикатор. См. [Как определяется состояние «работает»](/ru/apps/types/#как-определяется-состояние-работает). |
| остановлено | Ничего из перечисленного. Серый индикатор. |
| управляемое | Moonpool запустил его в этом сеансе. Работающее приложение, которое не является управляемым, было запущено другим способом, и «Выход» его не трогает. |

Вкладка терминала и работающее приложение - разные вещи. Щелчок по названию приложения только
открывает вкладку его терминала; он никогда не запускает приложение. Закрытие вкладки никогда
не останавливает приложение.

## Окна и части

| Термин | Значение |
| --- | --- |
| хаб | Постоянно работающий процесс Moonpool и его главное окно. В названиях инструментов он называется «launcher». |
| главное окно | Основное окно: боковая панель слева, панель CLI справа. |
| трей | Значок в системном трее и его меню (**Показать Moonpool**, **Выход**). |
| боковая панель | Левая часть главного окна: поле фильтра, меню **...** и строки приложений. |
| панель CLI | Правая часть главного окна, где находятся вкладки терминала. |
| вкладка терминала | Терминал одного приложения на панели CLI. |
| подстрока MCP | Приглушённая строка под приложением, показывающая его собственный вспомогательный процесс `<exe> mcp`. |
| редактор приложений | Диалог «Добавить приложение» и «Изменить приложение». |

## Файлы и папки

| Термин | Значение |
| --- | --- |
| папка конфигурации | Папка, где хранятся `apps.json` и другие файлы Moonpool. Токен `{MP_DATA}`. См. [Где хранится конфигурация](/ru/apps/apps-json/#где-находится-конфигурация). |
| `{MP_HOME}` | Папка Moonpool: `%USERPROFILE%\.moonpool` для установленной копии, папка `.moonpool\` портативной копии, папка конфигурации в Linux. |
| сеанс | Один запуск хаба, от старта до выхода. |
| журнал сеанса | Файл со всем, что приложение вывело за один сеанс, в `cli-output\`. См. [Журналы](/ru/data/logs/). |
| `moonpool.log` | Собственный отладочный журнал Moonpool, который пишется только при включённом параметре **Записывать отладочные данные в файл**. |
| дамп | Копия журнала сеанса в виде простого текста, созданная командой `dump`. |
| снимок | Копия исправного `apps.json` в `apps.json.history\`. См. [Резервное копирование и восстановление](/ru/data/backup-and-recovery/). |

## Режимы

| Термин | Значение |
| --- | --- |
| установленный | Moonpool в `%USERPROFILE%\.moonpool` с ярлыком в меню «Пуск» и записью в «Установке и удалении программ». Только Windows. |
| портативный | Moonpool в выбранной вами папке `.moonpool\`, отмеченной файлом `moonpool.portable`. См. [Портативный режим](/ru/data/portable-mode/). |
| копия | Одна папка Moonpool, установленная или портативная. Каждая копия работает независимо. |

## Остановка и автоматизация

| Термин | Значение |
| --- | --- |
| `killMode` | Дополнительный шаг, который выполняет остановка после завершения терминала приложения. См. [Остановка и перезапуск](/ru/apps/stop-and-restart/). |
| `stopCommand` | Команда, которую выполняет остановка при `killMode` равном `command`. |
| `processName` | Имя процесса, которое отслеживает Moonpool и которое он завершает в режиме `processName`. |
| канал управления | Именованный канал (Windows) или сокет Unix (Linux, macOS), на котором отвечает хаб. См. [Команды управления](/ru/automation/control-verbs/). |
| команда (verb) | Командное слово, например `launch` или `reload`, передаваемое в командной строке или по каналу управления. |
| ticket | Ключ, добавляемый через `--ticket`, чтобы прочитать результат команды в `state.json`. |
| токен | Метка версии `apps.json`, которую должна нести запись конфигурации. |
| MCP-помощник (shim) | Процесс `<exe> mcp`, который запускает ИИ-хост, чтобы получить доступ к инструментам самого приложения. |
