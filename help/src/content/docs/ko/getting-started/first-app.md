## 1. Moonpool 시작

Windows에서는 `moonpool.exe`를 실행하고 **Moonpool 설치**를 클릭합니다([설치](/ko/getting-started/install/)
참고). Linux에서는 AppImage 또는 설치된 패키지를 실행합니다.

Moonpool을 처음 실행하면 사이드바에 예제 앱이 채워집니다(Windows의 메모장, 셸, 작은 웹 서버,
함께 제공되는 대시보드). 이 앱들은 그대로 실행되므로(웹 서버에는 Python이 필요합니다) 먼저
사용해 본 뒤 편집하거나 삭제하면 됩니다. 시스템 트레이에도 아이콘이 표시됩니다. Windows에서
아이콘이 보이지 않으면 작업 표시줄 오른쪽의 **^** 화살표를 클릭하세요.

## 2. 앱 추가

1. 사이드바 상단의 **...** 메뉴를 열고 **앱 추가**를 선택합니다.
2. **name**을 입력합니다. 그룹은 처음에 `Web apps`로 되어 있으며, 그대로 두거나 다른 그룹을 고를 수 있습니다.
3. 개발 서버라면 **type**을 `web`으로 둡니다.
4. **cwd**에는 프로젝트 폴더를, **command**에는 앱을 시작할 때 입력하는 명령(예: `npm run dev`)을 설정합니다.
5. **port**에는 앱이 대기하는 포트를, **url**에는 열 페이지를 설정합니다.
6. 저장합니다.

각 필드의 자세한 내용은 [앱 추가](/ko/apps/add-an-app/)에 있습니다.

## 3. 앱 시작

앱의 **실행** 버튼(행에 있는 재생 아이콘)을 클릭합니다. 터미널 탭이 열리고 출력이 표시됩니다.
앱이 시작되는 동안 상태 점이 깜박이다가, 포트가 응답하면 단색으로 바뀝니다. **openBrowser**가
켜져 있으면 페이지가 열립니다.

앱 이름을 클릭하면 터미널 탭만 열립니다. 앱이 시작되지는 않습니다.

## 4. 앱 중지

행의 **중지** 버튼(사각형)을 클릭합니다. 점이 회색으로 바뀝니다.

중지한 뒤에도 무언가 계속 실행되고 있다면 [중지와 다시 시작](/ko/apps/stop-and-restart/)을 참고하세요.

## 에이전트에게 맡기기

열린 탭이 없으면 CLI 창에 **프롬프트 복사** 버튼이 표시됩니다. 이 프롬프트를 AI 에이전트에게
붙여 넣으면 에이전트가 앱을 찾아 추가합니다. [AI 에이전트: 빠른 시작](/ko/automation/quick-start/)을
참고하세요.

## 나중에 허브 찾기

- 트레이 아이콘을 왼쪽 클릭하면 허브가 표시됩니다. 오른쪽 클릭하면 **Moonpool 표시**와
  **종료**가 있는 메뉴가 나타납니다.
- 기본적으로 창을 닫으면 Moonpool이 종료됩니다. 설정에서 **닫을 때 트레이로 숨기기**를 켜면
  종료하지 않고 트레이로 숨겨 계속 실행합니다. [트레이, 닫기, 최소화](/ko/using/tray-and-closing/)를
  참고하세요.

## 도움말 보기

오프라인에서도 동작하며 실행 중인 버전과 항상 일치합니다.
