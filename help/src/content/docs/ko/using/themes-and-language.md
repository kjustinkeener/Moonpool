테마, 언어, 투명도는 [설정 창](/ko/using/settings/)에서 지정합니다.
세 가지 모두 열려 있는 모든 Moonpool 창에 즉시 적용됩니다.

![설정 상단의 언어(1)와 테마(2) 선택기](../../../../assets/screenshots/settings-language-theme.png)

1. 언어 선택기.
2. 테마 버튼. 현재 테마의 이름을 표시하며 테마 브라우저를 엽니다.

## 테마

테마 브라우저는 별도의 창입니다. 테마마다 미리보기 카드가 하나씩 있고, 각 카드는 해당 테마의 색상
(텍스트, 패널, 입력란, 버튼, 상태 점, 게이지 그라데이션, 16색 터미널 세트)으로 그려져 있으며,
기본, 네온, 따뜻한 색, 차가운 색, 그린, 중립, 라이트, 블러시, 선명한 색, 연한 파스텔, 파스텔로
묶여 있습니다. 카드를 클릭하면 적용됩니다. 열려 있는 모든 Moonpool 창이 한꺼번에 바뀌고 선택이
저장됩니다. 비교할 수 있도록 창은 열린 채로 유지되며, Esc를 누르면 닫힙니다.

테마는 68개에 자동이 더해지며, 절반 정도가 밝은 테마입니다. 테마 이름은 고유 명사이므로 번역하지
않습니다. 번역되는 것은 자동 (시스템), 다크, 라이트뿐입니다.

**자동 (시스템)**은 운영 체제의 밝은/어두운 설정을 따르며, 운영 체제가 바뀌면 실시간으로 전환됩니다.
그 밖의 선택은 고정됩니다. 터미널의 ANSI 16색도 테마를 따릅니다.

이전 버전에서 저장한 테마는 그대로 유지됩니다. Moonpool이 더 이상 알지 못하는 이름으로 저장되어
있으면 자동으로 되돌아갑니다. 일부 레이블은 이전과 다릅니다(예를 들어 Matrix는 이제 Terminal로,
Nord는 Arctic으로, Dracula는 Nocturne으로, Gruvbox는 Retro로, Solarized는 Solar로 표시됩니다).
저장된 선택 자체는 바뀌지 않습니다.

테마는 `settings.json`이 아니라 웹뷰의 `localStorage`에 저장됩니다. 저장소를 사용할 수 없으면 자동으로
되돌아갑니다.

```text
localStorage key: moonpool.theme
```

## 언어

자동은 운영 체제의 언어를 따릅니다. 그렇지 않으면 14개 중에서 고르며, 각각 해당 언어로 표시됩니다.

```text
English, Deutsch, Español, Français, Italiano, 日本語, 한국어, Nederlands, Polski,
Português (Brasil), Русский, Türkçe, 简体中文, 繁體中文
```

선택기는 허브와 다른 창에 즉시 적용됩니다. 선택한 값은 `settings.json`에 `locale`로 저장됩니다.

## 투명도

**배경 투명도**는 창 배경을 비치게 만들며, 0%(불투명)에서 90%까지입니다.

- 창 위에 포인터를 올리면 즉시 완전히 불투명해집니다. 포인터가 벗어나면 약 2초에 걸쳐 설정한 값으로 서서히 돌아갑니다.
- 터미널은 자체 색조를 더하지 않고 같은 색조를 따릅니다.
- 각 창(허브, 설정, 정보, 앱 편집기, 테마 브라우저)이 설정을 직접 적용하며, 슬라이더를 끌면 설정이 다른 창을 실시간으로 업데이트합니다.

## UI 배율

Ctrl + 마우스 휠로 인터페이스 전체를 확대/축소합니다. 키보드 확대/축소는 없습니다.
[단축키와 확대/축소](/ko/using/keyboard-shortcuts/)를 참고하세요.
