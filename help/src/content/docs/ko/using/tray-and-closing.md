## 트레이 아이콘

| 동작 | 결과 |
| --- | --- |
| 왼쪽 클릭 | 허브 창을 표시합니다(최소화되었거나 숨겨져 있으면 복원합니다). |
| 오른쪽 클릭 | **Moonpool 표시**와 **종료**만 있는 메뉴(설정한 언어로 표시됩니다). |

Moonpool 복사본이 여러 개 실행 중이면 각각 자체 트레이 아이콘이 있습니다. 툴팁에 어느 복사본인지
표시됩니다. [포터블 모드](/ko/data/portable-mode/#여러-복사본을-동시에)를 참고하세요.

## 종료

**종료**는 Moonpool을 끝내며, Windows에서는 Moonpool이 실행한 모든 앱을 자식 프로세스까지 포함해
중지합니다. Moonpool이 발견하기 전에 이미 실행 중이던 앱("managed by Moonpool" 없이 실행 중으로
표시되는 앱)은 그대로 둡니다. Linux와 macOS에서는 종료해도 실행된 앱이 확실하게 중지되지는 않습니다.

## 닫기와 최소화

기본적으로 닫기 버튼은 Moonpool을 종료합니다(`closeToTray`가 `false`입니다). 설정에서 **닫을 때 트레이로
숨기기**를 켜면 닫을 때 창이 대신 트레이로 숨겨집니다. Moonpool은 계속 실행되며, 트레이 아이콘이나
**Moonpool 표시**로 다시 불러올 수 있습니다.

**최소화할 때 트레이로 숨기기**(`minimizeToTray`, 기본값 켜짐)는 창을 최소화하면 트레이로 숨기며,
작업 표시줄에서도 사라집니다. 끄면 평소처럼 작업 표시줄로 최소화됩니다.

## 트레이와 작업 표시줄 잠금

**트레이에 표시**와 **작업 표시줄에 표시**는 트레이 아이콘과 작업 표시줄 버튼이 보이는지 여부를
제어합니다. 적어도 하나는 켜져 있어야 합니다. 그렇지 않으면 숨겨진 창을 다시 불러올 방법이
없기 때문입니다. 하나만 켜져 있으면 그 확인란은 다른 하나를 다시 켤 때까지 비활성화됩니다.

## 항상 위에 표시

설정의 **항상 위에 표시**는 모든 Moonpool 창(허브, 설정, 정보, 앱 편집기, 테마 브라우저, 설치 프로그램,
도움말)을 다른 창보다 위에 유지합니다. 기본값은 꺼짐입니다.
