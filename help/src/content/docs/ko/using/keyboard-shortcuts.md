## 키보드

| 키 | 위치 | 동작 |
| --- | --- | --- |
| F5, Ctrl+R, Cmd+R | 허브 | 메뉴의 **새로 고침**과 같이 디스크에서 `apps.json`을 다시 읽습니다. 페이지 자체는 새로 고쳐지지 않습니다. |
| Esc | 컨텍스트 메뉴 | 메뉴를 닫습니다. |
| Esc | 앱 이름 바꾸기 | 이름 바꾸기를 취소합니다. |
| Esc | 설정, 정보, 앱 편집기 창 | 창을 닫습니다(편집기는 변경 사항을 버리기 전에 확인합니다). |
| Enter | 앱 이름 바꾸기 | 새 이름을 저장합니다. |

## 마우스

| 동작 | 위치 | 결과 |
| --- | --- | --- |
| Ctrl + 휠 | 허브 | UI를 확대/축소합니다. |
| 텍스트 선택 | 터미널 | 선택한 내용을 복사하고 선택을 해제합니다. |
| 가운데 클릭 | 터미널 | 붙여 넣습니다. |
| 오른쪽 클릭 | 사이드바 행 | 행 메뉴를 엽니다. [사이드바와 메뉴](/ko/using/sidebar-and-menus/)를 참고하세요. |

## 확대/축소

Ctrl을 누른 채 허브 위에서 휠을 스크롤하면 확대/축소됩니다. 위로 스크롤하면 확대되고 아래로 스크롤하면 축소되며, 휠 이벤트 한 번에 약 10퍼센트씩 변합니다.

```text
Ctrl + wheel up      zoom in
Ctrl + wheel down    zoom out
```

- 범위는 0.5배에서 3배까지입니다.
- 창도 같은 비율로 크기가 바뀌므로 2배에서도 1배일 때와 같은 밀도의 레이아웃이 유지됩니다. 한계에 도달하면 창은 더 이상 커지지 않습니다.
- 배율은 `settings.json`에 `uiScale`로 저장되며 다음 시작 때 적용됩니다. 저장된 창 크기는 이미 확대된 크기이므로 다시 배율이 적용되지 않습니다. [settings.json](/ko/data/settings-json/)을 참고하세요.

- 확대/축소는 허브 창에만 적용됩니다. 설정, 정보, 앱 편집기, 도움말은 각자의 크기를
  유지합니다.

설정에는 `uiScale` 컨트롤이 없으며 초기화 키도 없습니다. 원래 크기로 돌아가려면 같은 횟수만큼 휠을
반대로 돌리거나, Moonpool을 종료하고 `settings.json`에서 `uiScale`을 `1`로 설정한(또는 키를 삭제한) 뒤
다시 시작하세요.
