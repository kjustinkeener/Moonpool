사이드바에는 `apps.json`의 모든 앱이 각 앱의 `group` 필드에 따라 묶여 표시됩니다. [앱 필드](/ko/apps/fields/)를 참고하세요.

## 행

각 행에는 상태 점, 앱 아이콘(아이콘이 없으면 유형 글리프), 이름, 설정된 경우 포트(`:3000`), 컨트롤이 표시됩니다.

| 점 | 의미 |
| --- | --- |
| 단색 | 실행 중 |
| 깜박임 | 시작 중: Moonpool이 앱을 시작했지만 아직 구동이 감지되지 않았습니다 |
| 회색 | 중지됨 |

점에 마우스를 올리면 상태 이름이 표시됩니다.

![실행 중인 웹 앱 두 개가 강조 표시된 사이드바: 켜진 점과 중지 버튼](../../../../assets/screenshots/sidebar-running-narrow.png)

1. 실행 중인 앱 두 개. 점이 켜져 있고 실행 대신 중지(사각형)가 표시됩니다.

| 컨트롤 | 동작 |
| --- | --- |
| 연필 | 앱을 편집합니다. |
| 다시 시작 | 중지한 뒤 다시 실행합니다. 중지된 앱에서는 그냥 실행합니다. |
| 실행 (재생) | 앱을 시작하고 터미널 탭을 엽니다. 앱이 중지되어 있을 때 표시됩니다. |
| 중지 (사각형) | 앱을 중지합니다. 실행 중이거나 시작 중일 때 표시됩니다. |

![실행 중인 행 하나를 확대한 모습: 상태 점, 유형 아이콘, 이름과 포트, 그리고 편집, 다시 시작, 중지 버튼](../../../../assets/screenshots/sidebar-row-controls.png)

1. 상태 점(실행 중에는 켜짐).
2. 유형 아이콘.
3. 편집(연필).
4. 다시 시작.
5. 중지(실행 중에는 실행 대신 표시됨).

실행이나 중지가 진행되는 동안에는 컨트롤이 스피너(`처리 중...`)로 바뀝니다.

앱 **이름**을 클릭하면 터미널 탭이 열리거나 포커스를 받을 뿐, 아무것도 실행하지 않습니다. 중지된 앱의 탭에는 이번 세션의 로그가 표시됩니다. 시작하려면 실행이나 다시 시작을 사용하세요. `url`만 있고 `command`가 없는 `static` 앱에는 터미널이 없습니다. 실행하면 브라우저에서 URL이 열립니다.

### 툴팁

이름에 마우스를 올리면 앱에 `note`가 있을 경우 `note`가, 없으면 앱 이름이 표시됩니다. `note`는 편집기나 `apps.json`에서 설정합니다.

### MCP 하위 행

AI 클라이언트가 앱 자체의 MCP 도구를 사용하면 앱 아래에 흐리게 표시되는 `MCP 서버` 하위 행이 나타납니다.
클라이언트가 연결되어 있는 동안에는 점이 켜지고 툴팁에 "MCP 클라이언트 연결됨"이라고 표시됩니다. 중지
버튼으로 해당 프로세스를 종료합니다.

이 행은 `processName`과 `mcp` 인수로 프로세스를 찾으며, 앱에 `mcpProcessName` 패턴이 설정되어 있으면 그
패턴으로 찾습니다. [필드](/ko/apps/fields/#mcpprocessname)를 참고하세요.

이 행을 숨기려면 설정의 **MCP 프로세스 표시**를 끄세요.
[MCP 설정](/ko/automation/mcp-setup/#자체-mcp-서버가-있는-앱)을 참고하세요.

## 그룹

![다섯 개의 그룹 헤더가 강조 표시된 유휴 상태의 사이드바. 각 헤더 오른쪽에 앱 개수가 있습니다](../../../../assets/screenshots/sidebar-groups-narrow.png)

- 그룹 제목을 클릭하면 접거나 펼칩니다. 옆의 숫자는 표시된 앱의 개수입니다. 접힌 그룹은 기억됩니다.
- 그룹 안에서는 가장 최근에 시작한 앱이 맨 위에 옵니다. 한 번도 시작하지 않은 앱은 `apps.json`의 순서를 유지합니다. 방금 실행한 앱은 빛나면서 맨 위로 올라갑니다.

## 검색 상자

**앱 검색...**에 입력해서 목록을 좁힙니다. 대소문자를 구분하지 않고 앱 이름과 그룹 이름에서 찾습니다. 일치하는 항목이 없으면 목록에 다음과 같이 표시됩니다.

```text
‘<text>’과(와) 일치하는 앱이 없습니다.
```

앱에서는 이 문구와 아래의 삭제 확인 문구 모두 텍스트 주위에 둥근 따옴표가 표시됩니다.

## 오른쪽 클릭 메뉴

행을 오른쪽 클릭하면 다음 항목이 나타납니다.

| 항목 | 동작 |
| --- | --- |
| 편집 | 앱 편집기를 엽니다. |
| 이름 바꾸기 | 이름을 입력란으로 바꿉니다. **Enter**를 누르거나 다른 곳을 클릭하면 저장되고 **Esc**를 누르면 취소됩니다. 비어 있거나 바뀌지 않은 이름은 무시됩니다. |
| 아이콘 설정... | 아이콘으로 사용할 이미지 파일(png, jpg, jpeg, gif, svg, webp, ico)을 선택합니다. |
| 삭제 | ‘<name>’을(를) 삭제할까요?를 묻고 `apps.json`에서 항목을 삭제합니다. Moonpool이 앱을 실행 중이면 먼저 중지합니다. |

**Esc**를 누르면 아무 동작 없이 메뉴가 닫힙니다.

## 크기 조절

사이드바와 CLI 창 사이의 구분선을 끕니다. 너비는 180에서 620 px로 제한되며(기본값 280) 기억됩니다. CLI 창이 접혀 있는 동안에는 구분선이 잠깁니다. [터미널 탭](/ko/using/terminal-tabs/)을 참고하세요.
