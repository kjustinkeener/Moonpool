Moonpool은 트레이 실행 허브입니다. 로컬 앱과 개발 서버마다 실행 명령, 작업 디렉터리, 환경 변수를
한곳에 보관하고, 각각을 전용 터미널에서 실행합니다. 창을 찾아 헤매거나 명령을 다시 입력할 필요가 없습니다.

## Moonpool이 제공하는 것

- **모든 것을 한곳에서 시작합니다.** 앱의 실행 버튼(행에 있는 재생 아이콘)을 클릭하면 앱이
  시작됩니다. 이름을 클릭하면 터미널 탭만 열립니다. Moonpool은 앱의 실행 여부를 추적하고
  출력을 보여 줍니다.
- **앱마다 전용 터미널이 있습니다.** 각 앱은 관리되는 터미널에서 실행되므로 로그가
  섞이지 않습니다.
- **어디든 함께 이동합니다.** 컴퓨터에 설치해서 쓰거나, 모든 데이터를 옆에 둔 채 USB 메모리의
  포터블 폴더에서 실행할 수 있습니다.
