## 앱

| 용어 | 의미 |
| --- | --- |
| 앱 | Moonpool이 관리하는 하나의 대상: 개발 서버, 데스크톱 앱, 페이지 또는 명령입니다. |
| 항목(entry) | `apps.json`에 있는 앱의 레코드입니다. JSON을 이야기할 때만 사용합니다. |
| 앱 행 | 사이드바에서 상태 점과 컨트롤이 있는 앱의 줄입니다. |
| 그룹 | 앱이 속한 사이드바 제목이며 `group` 필드에서 옵니다. |
| 유형(type) | `web`, `desktop`, `static`, `cli` 중 하나입니다. 어떤 필드가 중요한지 결정합니다. [앱 유형](/ko/apps/types/)을 참고하세요. |
| id | 파일 이름, 명령, 에이전트 도구에서 쓰는 앱의 고정 키입니다. [id](/ko/apps/apps-json/#id)를 참고하세요. |

## 앱 상태

| 상태 | 의미 |
| --- | --- |
| 시작 중 | Moonpool이 앱을 실행했지만 아직 올라온 것을 확인하지 못했습니다. 깜박이는 점. |
| 실행 중 | `port`가 응답하거나, `processName`이 존재하거나, 둘 다 설정되지 않았다면 Moonpool이 시작한 터미널이 아직 살아 있습니다. 채워진 점. [실행 중 여부를 판단하는 방법](/ko/apps/types/#실행-중-여부를-판단하는-방식)을 참고하세요. |
| 중지됨 | 위의 어느 것에도 해당하지 않습니다. 회색 점. |
| 관리됨(managed) | 이번 세션에서 Moonpool이 시작했습니다. 관리되지 않는 실행 중인 앱은 다른 방법으로 시작된 것이며, 종료해도 그대로 남습니다. |

터미널 탭과 실행 중인 앱은 별개입니다. 앱 이름을 클릭하면 터미널 탭만 열리고 앱은 시작되지 않습니다. 탭을 닫아도 앱은 중지되지 않습니다.

## 창과 구성 요소

| 용어 | 의미 |
| --- | --- |
| 허브 | 상주하는 Moonpool 프로세스와 그 메인 창입니다. 도구 이름에서는 "launcher"라고 부릅니다. |
| 허브 창 | 메인 창: 왼쪽에 사이드바, 오른쪽에 CLI 창이 있습니다. |
| 트레이 | 시스템 트레이 아이콘과 그 메뉴(**Moonpool 표시**, **종료**)입니다. |
| 사이드바 | 허브 창의 왼쪽: 필터 상자, **...** 메뉴, 앱 행입니다. |
| CLI 창 | 허브 창의 오른쪽으로, 터미널 탭이 들어 있습니다. |
| 터미널 탭 | CLI 창에 있는 앱 하나의 터미널입니다. |
| MCP 하위 행 | 앱 아래에 흐리게 표시되며 앱 자체의 `<exe> mcp` 도우미 프로세스를 보여 주는 행입니다. |
| 앱 편집기 | 앱 추가와 앱 편집 대화상자입니다. |

## 파일과 폴더

| 용어 | 의미 |
| --- | --- |
| 설정 폴더 | `apps.json`과 Moonpool의 다른 파일이 들어 있는 폴더입니다. `{MP_DATA}` 토큰입니다. [설정이 있는 위치](/ko/apps/apps-json/#설정-위치)를 참고하세요. |
| `{MP_HOME}` | Moonpool 폴더: 설치형은 `%USERPROFILE%\.moonpool`, 포터블 복사본은 그 `.moonpool\` 폴더, Linux는 설정 폴더입니다. |
| 세션 | 허브가 시작해서 종료할 때까지의 한 번의 실행입니다. |
| 세션 로그 | 한 세션 동안 앱이 출력한 모든 내용을 담은 파일로, `cli-output\` 아래에 있습니다. [로그](/ko/data/logs/)를 참고하세요. |
| `moonpool.log` | Moonpool 자체의 디버그 로그로, **디버그 정보를 파일에 기록**이 켜져 있을 때만 기록됩니다. |
| 덤프 | `dump` 동사로 만든 세션 로그의 일반 텍스트 복사본입니다. |
| 스냅샷 | `apps.json.history\`에 있는 정상 `apps.json`의 복사본입니다. [백업과 복구](/ko/data/backup-and-recovery/)를 참고하세요. |

## 모드

| 용어 | 의미 |
| --- | --- |
| 설치형 | `%USERPROFILE%\.moonpool`에 있는 Moonpool로, 시작 메뉴 바로 가기와 프로그램 추가/제거 항목이 있습니다. Windows 전용입니다. |
| 포터블 | 직접 고른 `.moonpool\` 폴더에 있는 Moonpool로, `moonpool.portable` 파일로 표시됩니다. [포터블 모드](/ko/data/portable-mode/)를 참고하세요. |
| 복사본 | 설치형이든 포터블이든 하나의 Moonpool 폴더입니다. 각 복사본은 독립적으로 실행됩니다. |

## 중지와 자동화

| 용어 | 의미 |
| --- | --- |
| `killMode` | 앱의 터미널을 끝낸 뒤 중지가 수행하는 추가 단계입니다. [중지와 다시 시작](/ko/apps/stop-and-restart/)을 참고하세요. |
| `stopCommand` | `killMode`가 `command`일 때 중지가 실행하는 명령입니다. |
| `processName` | Moonpool이 감시하고, `processName` 모드에서 종료하는 프로세스 이름입니다. |
| 제어 채널 | 허브가 응답하는 이름 있는 파이프(Windows) 또는 Unix 소켓(Linux, macOS)입니다. [제어 동사](/ko/automation/control-verbs/)를 참고하세요. |
| 동사(verb) | `launch`나 `reload` 같은 명령어로, 명령줄이나 제어 채널로 전달합니다. |
| 티켓 | `--ticket`으로 붙여서 `state.json`에서 명령의 결과를 읽는 데 쓰는 키입니다. |
| 토큰 | 설정 쓰기에 반드시 포함해야 하는 `apps.json`의 버전 표식입니다. |
| MCP 도우미(shim) | AI 호스트가 앱 자체의 도구에 접근하려고 시작하는 `<exe> mcp` 프로세스입니다. |
